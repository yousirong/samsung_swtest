# [프로그래머스] 2025 카카오 하반기 1차 - 바이러스 파이프

`swtest/` 의 표준입출력형 풀이를 프로그래머스 제출형으로 옮긴 것이다.
**코드는 swtest 판과 같다.** `input()`이 인자를 받고 `main()`이 `solution()`이 된 것만 다르다.

| 항목 | 내용 |
|---|---|
| 원본 | [swtest/프로그래머스_2025_하반기1차_바이러스파이프.cpp](../../swtest/프로그래머스_2025_하반기1차_바이러스파이프.cpp) |
| 문제 | 프로그래머스 코딩테스트 연습 "바이러스 파이프" (개별 주소 확인 필요) |
| 반환 타입 | `int` |
| 제출 파일 | `solution.cpp` (통째로 붙여 넣기) |
| 로컬 테스트 | `local_test.cpp` (제출하지 않음) |

## 시그니처

```cpp
int solution(int n, int infection, vector<vector<int>> edges, int k)
```

## 원본 stdin을 어떻게 인자로 바꿨나

`local_test.cpp` 가 원본과 똑같은 형식으로 읽어 `solution()`에 넘긴다. 매개변수 순서(`n, infection, edges, k`)를 그대로 따랐다.

```cpp
scanf("%d %d", &n, &infection);   // 원본 scanf 순서 그대로
scanf("%d %d %d", &edges[i][0], &edges[i][1], &edges[i][2]);   // n - 1줄
scanf("%d", &k);
```

예제 1을 stdin으로 쓰면 이렇다.

```
10 1
1 2 1
1 3 1
1 4 3
1 5 2
5 6 1
5 7 1
2 8 3
2 9 2
9 10 1
2
```

## 바뀐 지점

| 위치 | 변경 |
|---|---|
| 헤더 | `#include <vector>` 추가, `using namespace std;` (프로그래머스 템플릿과 같은 형태) |
| `input()` | `scanf`를 인자 대입으로 교체. 인접 리스트 만들기와 초기화는 원본 그대로 |
| `main()` → `solution()` | `printf` → `return` |
| 로직 함수 | 무변경. 전역 배열 + BFS + DFS 백트래킹 그대로다 |

## 이 문제만의 포인트

- **결정할 것은 "몇 번째에 어떤 종류를 열까" 뿐이다.** 종류 3개, 행동 최대 10번이라 많아야 3^10가지.
  삼성 기출의 2048 게임처럼 "하나 고르고 시뮬레이션 → 원상복구" 하는 DFS로 전부 해 본다.
- **한 번 열면 닿는 데까지 다 번진다.** 감염된 노드를 전부 큐에 넣고, 연 종류의 간선만 따라가는 BFS 한 번이 행동 1번이다.
- **같은 종류를 연달아 열 필요는 없다.** 첫 번째에서 이미 다 퍼졌다. 직전 종류를 건너뛰면 3갈래가 2갈래가 된다.
- **새로 감염된 게 0이면 그 가지는 버린다.** 상태는 그대로이고 행동만 하나 날린 것이다.
- 감염 상태는 DFS 지역 배열 `backup[]` 에 백업했다가 돌아올 때 되돌린다. 깊이가 최대 10이라 부담이 없다.
- "최대" k번이므로 깊이마다 `answer`를 갱신한다 (k번을 다 채울 필요가 없다).

## 검증에 쓴 방법

- 문제의 입출력 예 2개(6, 7)를 통과했다.
- 가지치기 없이 **3^k가지 순서를 전부 나열**하고, 간선을 반복해서 훑어 감염을 퍼뜨리는 별도 구현과 무작위 400개를 비교해 전부 일치했다.
- 제출형은 swtest 판과 무작위 300개를 `cmp` 대조했고, `-DREPEAT_TEST` 재호출 검사도 통과했다.
- 최대 크기(n = 100, k = 10)에서 50ms 미만.

## 로컬 테스트

```bash
cd programmers/2025카카오1차_바이러스파이프
g++ -O2 -o run local_test.cpp                # solution.cpp 를 include 해서 빌드
g++ -O2 -DREPEAT_TEST -o rep local_test.cpp  # 재호출 검사
g++ -O2 -o orig ../../swtest/프로그래머스_2025_하반기1차_바이러스파이프.cpp
./orig < in.txt > a.txt; ./run < in.txt > b.txt; cmp a.txt b.txt
```

> 제출할 때는 `solution.cpp` 를 통째로 붙여 넣는다. `local_test.cpp` 는 제출하지 않는다.
