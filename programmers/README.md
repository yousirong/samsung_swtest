# 프로그래머스 함수형 변환

`swtest/`의 표준입출력형 풀이를 **프로그래머스 함수형(`solution` 함수) 제출용**으로 옮긴 것이다.

| | 코드트리 / 백준 / SWEA | 프로그래머스 (함수형) |
|---|---|---|
| 입력 | 프로그램이 stdin에서 직접 읽음 (`scanf`) | 채점기가 인자로 넘겨줌 |
| 출력 | 프로그램이 직접 출력 (`printf`) | `return` 하면 채점기가 비교 |
| `main()` | 내가 작성 | 채점기가 갖고 있음 |

알고리즘은 이미 `swtest/`에서 검증됐다. 여기서 연습하는 것은 **입출력 껍데기를 바꾸는 작업 그 자체**다.

---

## 공통 규칙

### 1. 원본 로직은 건드리지 않는다

바뀌는 곳은 세 군데뿐이고 전부 표시를 단다.

| 마커 | 뜻 |
|---|---|
| `// [수정]` | 원래 있던 줄을 고침 (scanf → 인자 대입, printf → return, main → solution) |
| `// [추가]` | 원래 없던 줄을 새로 넣음 (include, 재호출 초기화) |
| `// [버그수정]` | 원본 버그를 고친 곳 (드묾. README에 근거를 반드시 적는다) |

### 2. `using namespace std;`를 쓰지 않는다

전역 배열 이름이 `std` 이름과 겹쳐 **컴파일이 깨지는 파일이 여럿 있다.**

| 원본 | 전역 선언 | 충돌 |
|---|---|---|
| 2019하오후2 윷놀이사기단 | `int move[]`, `int next[][]` | `std::move`, `std::next` |
| 21 덱, 22 회전하는큐 | `int deque[]` | `std::deque` |
| 24 바이러스DFS | `int count;` | `std::count` |
| 17 스택, 19·20·25·26 | `int stack[]`, `int queue[]` | `std::stack`, `std::queue` |
| 2017상오전2 외주수익, 2020상오후1 승자독식모노폴리 | `int time[]` | `::time` |

```
error: reference to 'move' is ambiguous
```

그래서 **`std::vector` / `std::string`을 전부 명시**한다. 규칙 하나로 예외 없이 적용된다.

### 3. `solution()`은 언제나 한 케이스

원본에 `T` 루프나 `0`-종료 루프가 있어도 `solution()`은 한 케이스만 처리한다. 루프는 하네스가 돈다.

### 4. 반환 타입

| 원본 출력 | 반환 |
|---|---|
| 정수 1개 | `int` (`%lld`면 `long long`) |
| 정수 2~3개 | `std::vector<int>` — **원본 출력 순서 그대로** |
| 명령마다 1줄 | `std::vector<int>` |
| 격자 전체 | `std::vector<std::vector<int>>` |
| 케이스마다 문자열 | `std::vector<std::string>` |

### 5. 인자 순서 = 원본 `scanf` 순서

배열 길이로 알 수 있는 값(`N`, `M`, `Q` 등)만 인자에서 뺀다.

> **축 순서를 "고쳐 주지" 않는다.** `38_BOJ_7576`은 `M N`(가로·세로), `38_BOJ_7569`는 `M N H`, `40_BOJ_2234`도 `M N` 순이다. 자연스러워 보인다고 `n, m`으로 바꾸면 하네스도 같이 바뀌어 **대조는 통과하는데 제출하면 틀린다.**

## 검증 방법

`solution.cpp` 맨 아래에 `#ifdef LOCAL_TEST`로 감싼 `main`이 들어 있다.
원본과 **똑같은 형식으로 읽고 똑같은 형식으로 출력**하므로 바이트 단위 대조가 된다.

```bash
cd programmers/<문제>
g++ -O2 -DLOCAL_TEST -o run solution.cpp                       # 대조용
g++ -O2 -DLOCAL_TEST -DREPEAT_TEST -o rep solution.cpp         # 재호출 검사용
g++ -O2 -o orig ../../swtest/<원본>.cpp                         # 기준

./orig < in.txt > a.out
./run  < in.txt > b.out
cmp a.out b.out          # diff 대신 cmp — 줄 끝 공백/마지막 개행 차이를 놓치지 않는다
./rep  < in.txt          # "NOT RE-ENTRANT"가 안 나오면 통과
```

통과 기준 4가지

1. `-DLOCAL_TEST` **없이** 빌드하면 `main`이 없어 링크가 실패한다 → 제출 코드가 순수함
2. `-DLOCAL_TEST` 빌드 성공
3. 랜덤 입력 300개 전부 `cmp` 일치
4. `-DREPEAT_TEST` 전부 통과

> 제출할 때는 `#ifdef LOCAL_TEST` 블록을 빼고 복사한다.

### 재호출 안전성이 왜 중요한가

원본은 프로세스당 한 번만 돌아서 전역이 더러워도 문제가 없었다. 함수형은 그 가정이 깨진다.
아래 파일들은 전역을 되돌리지 않으므로 변환할 때 초기화를 추가해야 한다.

| 원본 | 되돌려지지 않는 전역 |
|---|---|
| 2018상오후1 드래곤커브 | `MAP` — 치명적 |
| 2021하오전2 냉방시스템 | `wall`, `temperature` — 치명적 |
| 2020하오후1 청소는즐거워 | `tcnt` |
| 2016하1 정육면체굴리기 | `cube` |
| 2020상오후1 승자독식모노폴리 | `time[][]` |
| 2020하오전1 불안한무빙워크 | `position[]` |
| 24 · 25 · 26 · 34 · 36 · 41 (BOJ) | `MAP`, `visit` 등 |
