# 17 — 스택 (BOJ 10828)

| 항목 | 내용 |
|---|---|
| 유형 | G02 스택·큐·덱 |
| 소스 | [swtest/17_BOJ_10828_스택.cpp](../../../swtest/17_BOJ_10828_스택.cpp) |
| 링크 | https://www.acmicpc.net/problem/10828 |
| 구조 | 명령 N개 처리 |

## 1. 문제 요약
스택을 직접 구현하고 N개의 명령을 처리한다.

| 명령 | 동작 |
|---|---|
| `push X` | 정수 X를 스택에 넣는다 |
| `pop` | 맨 위 정수를 빼고 출력. 비었으면 `-1` |
| `size` | 스택에 든 정수의 개수 출력 |
| `empty` | 비었으면 `1`, 아니면 `0` |
| `top` | 맨 위 정수 출력(제거 안 함). 비었으면 `-1` |

## 2. 필요한 이론
→ [G02 스택·큐·덱 — 스택](../../theory/G02_스택큐덱.md)

**이 문제가 곧 이론 카드다.** 이후 모든 스택 사용의 원형이 여기서 나온다.

핵심 규약 하나: **`sp` 는 "다음에 값이 들어갈 위치"** 다.
```
sp = 0                 → 비어 있음
push(10)  → stack[0] = 10, sp = 1
push(20)  → stack[1] = 20, sp = 2
top       → stack[sp-1] = stack[1] = 20
```
`sp` 를 "마지막 원소 위치"로 잡는 유파도 있지만, 이 레포는 **다음 자리** 규약으로 통일되어 있다. 하나만 골라 끝까지 쓰는 게 중요하다.

## 3. 코드 흐름
```
main()
 └ sp = 0
   scanf(N)
   for N번:
      scanf(command)
      strCompare 로 분기:
         push  → scanf(value); stack[sp++] = value
         pop   → sp != 0 ? printf(stack[--sp]) : printf(-1)
         size  → printf(sp)
         empty → printf(sp != 0 ? 0 : 1)
         top   → sp != 0 ? printf(stack[sp-1]) : printf(-1)
```

## 4. 핵심 코드

### 자료구조 — 두 줄이 전부
```c
int stack[MAX];   // 배열로 구현한 스택
int sp;           // stack pointer (다음에 들어갈 위치)
```

### 다섯 연산
```c
stack[sp++] = value;                        // push : 넣고 증가 (후위)

printf("%d\n", stack[--sp]);                // pop  : 감소 후 읽기 (★ 전위)

printf("%d\n", sp);                         // size

printf("%d\n", sp != 0 ? 0 : 1);            // empty

printf("%d\n", stack[sp - 1]);              // top  : 감소 없이
```

**`push` 는 후위 증가, `pop` 은 전위 감소.** 이 비대칭이 "sp = 다음 자리" 규약의 직접적 결과다.
- `sp` 가 가리키는 곳은 아직 빈 자리 → 거기 쓰고 나서 증가
- 빼낼 값은 `sp` 바로 앞 → 먼저 내려간 뒤 읽기

### 자체 strcmp
```c
int strCompare(const char* a, const char* b)
{
    // 두 문자열이 같을 때까지 계속 비교
    while (*a && *a == *b) { ++a; ++b; }

    // 다른 문자가 나오면 그 차이를 반환
    return *a - *b;
}
```
같으면 `0`. 그래서 분기가 `if (strCompare(command, "push") == 0)` 형태다.

### 디버그 함수
```c
void printStack()
{
    for (int i = sp - 1; i >= 0; i--)   // 위에서 아래로
        printf("%d ", stack[i]);
    putchar('\n');
}
```
스택은 **역순 출력**이 직관적이다. 이후 시뮬레이션 문제의 `printMap()` 과 같은 역할.

## 5. 예제 손 추적

명령: `push 1` `push 2` `top` `size` `empty` `pop` `pop` `pop` `size` `empty` `pop` `push 3` `empty` `top`

| 명령 | 동작 | `sp` | 배열 상태 | 출력 |
|---|---|---|---|---|
| 시작 | — | 0 | `[]` | |
| `push 1` | `stack[0]=1, sp=1` | 1 | `[1]` | |
| `push 2` | `stack[1]=2, sp=2` | 2 | `[1,2]` | |
| `top` | `stack[1]` | 2 | `[1,2]` | `2` |
| `size` | `sp` | 2 | | `2` |
| `empty` | `sp != 0` | 2 | | `0` |
| `pop` | `sp→1`, `stack[1]` | 1 | `[1]` | `2` |
| `pop` | `sp→0`, `stack[0]` | 0 | `[]` | `1` |
| `pop` | 비었음 | 0 | `[]` | `-1` |
| `size` | | 0 | | `0` |
| `empty` | | 0 | | `1` |
| `pop` | 비었음 | 0 | | `-1` |
| `push 3` | `stack[0]=3, sp=1` | 1 | `[3]` | |
| `empty` | | 1 | | `0` |
| `top` | `stack[0]` | 1 | | `3` |

> `pop` 이 실패해도 `sp` 는 건드리지 않는다. `if (sp != 0)` 안에서만 `--sp` 가 일어나는 구조라 자연스럽게 보장된다.
> `push 3` 이 다시 `stack[0]` 에 쓰는 것에 주목 — 스택은 **자리를 재활용**한다. (큐는 안 그렇다 → [19번](19_BOJ_10845_18258_큐_큐2.md))

## 6. 함정 / 예상 함정
- **★ `pop` 에서 후위 감소를 씀.** `stack[sp--]` 로 쓰면 아직 안 쓴 빈 자리를 읽는다. 반드시 `stack[--sp]`.
- **★ 빈 스택 검사 누락.** `pop`/`top` 은 `sp != 0` 확인이 필수. 안 하면 `stack[-1]` 을 읽는다 — 전역 배열이라 크래시 없이 **쓰레기값이 조용히 출력**된다.
- **`empty` 의 반환 방향.** 비었으면 `1` 이다. `sp != 0 ? 0 : 1` — 반대로 쓰기 쉽다.
- **`size` 를 `sp - 1` 로 출력.** `sp` 가 곧 개수다. "다음 자리" 규약이면 인덱스와 개수가 같아진다.
- **명령어 버퍼 크기.** `char command[100]` 이면 충분하지만, `%s` 는 길이 검사를 안 하므로 습관적으로 넉넉히 잡는다.
- `strCompare` 를 `==` 로 비교하려는 실수 — C 문자열은 포인터라 `command == "push"` 는 항상 거짓이다.

## 7. 백지 재현 체크리스트
- [ ] `sp` 가 "다음에 들어갈 자리"임을 기억하는가
- [ ] `push` 는 `stack[sp++]`, `pop` 은 `stack[--sp]` — 후위/전위를 구분하는가
- [ ] `top` 이 `stack[sp - 1]` 인가
- [ ] `size` 가 `sp` 인가
- [ ] `pop`/`top` 에 빈 검사(`sp != 0`)를 넣었는가
- [ ] `empty` 가 비었을 때 `1` 을 내는가
- [ ] `strCompare` 를 3줄로 쓸 수 있는가

## 8. 한 줄 요약
"`sp` 는 **다음 자리**. 그래서 push는 `[sp++]`, pop은 `[--sp]`, top은 `[sp-1]`."
