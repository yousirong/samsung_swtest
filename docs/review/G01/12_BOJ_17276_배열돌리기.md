# 12 — 배열 돌리기 (BOJ 17276)

| 항목 | 내용 |
|---|---|
| 유형 | G01 배열 회전·변환 |
| 소스 | [swtest/12_BOJ_17276_배열돌리기.cpp](../../../swtest/12_BOJ_17276_배열돌리기.cpp) |
| 링크 | https://www.acmicpc.net/problem/17276 |
| 구조 | T-loop (다중 테스트케이스) |

## 1. 문제 요약
N×N 배열과 각도 D(45의 배수, 음수 가능)가 주어진다. 배열을 D도만큼 회전시킨 결과를 출력한다.
단, 회전은 배열 전체가 아니라 **십자(가운데 행·열) + X자(주대각선·부대각선)** 위의 칸만 이동한다. 그 외 칸은 제자리다.

> N이 홀수이므로 가운데 행/열이 정확히 하나씩 존재한다.

## 2. 필요한 이론
→ [G01 배열 회전·변환](../../theory/G01_배열회전.md) — 특히 "읽는 배열과 쓰는 배열 분리"

이 문제만의 포인트: **회전 = 네 줄의 순환 교대**. 90도 회전 공식(`temp[M+1-c][r]`)이 아예 필요 없다.
십자와 X자를 이루는 네 줄을 각각 통째로 들어 옮기면 끝이다.

```
      가운데 열
          │
   ＼     │     ／
     ＼   │   ／
 ──────── ┼ ────────  가운데 행
     ／   │   ＼
   ／     │     ＼
  주대각선   부대각선
```

## 3. 코드 흐름
```
main()
 └ scanf(T) → for tc:
      input()                        N, D, 배열 입력
      count = |D / 45|               45도 회전을 몇 번 할지
      count번 반복:
         D >= 0 ? rotate45Clockwise() : rotate45CounterClockwise()
      printMap()
```

`rotate45Clockwise()` 는 네 줄을 한 칸씩 밀어 넣는다.
```
가운데 행 → 주대각선 → 가운데 열 → 부대각선 → (다시) 가운데 행
```
반시계는 화살표만 반대로 돌린 같은 코드다.

### 네 줄의 좌표 표현
| 줄 | 좌표 | N=3 에서 |
|---|---|---|
| 가운데 행 | `[half][c]`, `half = (N+1)/2` | `[2][1..3]` |
| 가운데 열 | `[r][half]` | `[1..3][2]` |
| 주대각선 (↘) | `[i][i]` | `[1][1] [2][2] [3][3]` |
| 부대각선 (↗) | `[i][N-i+1]` | `[1][3] [2][2] [3][1]` |

## 4. 핵심 코드

**읽기는 `temp`, 쓰기는 `MAP`** — 이 분리가 전부다.

```c
void rotate45Clockwise()
{
    // 현재 MAP 상태를 temp에 복사해 둠
    // 그래야 회전 중 값이 덮어써져도 원본 기준으로 안전하게 이동 가능
    copyMap(temp, MAP);

    int arr[MAX] = { 0 };          // 한 줄(행/열/대각선) 임시 저장용 배열
    int half = (N + 1) / 2;        // 가운데 인덱스

    // 1) 가운데 가로 행 -> 주대각선(왼쪽 위 ~ 오른쪽 아래)
    for (int c = 1; c <= N; c++) arr[c] = temp[half][c];
    for (int i = 1; i <= N; i++) MAP[i][i] = arr[i];

    // 2) 주대각선 -> 가운데 세로 열
    for (int i = 1; i <= N; i++) arr[i] = temp[i][i];
    for (int r = 1; r <= N; r++) MAP[r][half] = arr[r];

    // 3) 가운데 세로 열 -> 부대각선(오른쪽 위 ~ 왼쪽 아래)
    for (int r = 1; r <= N; r++) arr[r] = temp[r][half];
    for (int i = 1; i <= N; i++) MAP[i][N - i + 1] = arr[i];

    // 4) 부대각선 -> 가운데 가로 행
    for (int i = 1; i <= N; i++) arr[i] = temp[N - i + 1][i];
    for (int c = 1; c <= N; c++) MAP[half][c] = arr[c];
}
```

각 단계가 `읽기 루프` + `쓰기 루프` 두 줄 쌍으로 되어 있다. `arr` 은 한 줄을 잠깐 담는 버퍼일 뿐이고, 실제 안전장치는 `copyMap` 이다.

**각도 → 횟수 변환** (main)
```c
int count = D / 45;
// 음수면 절댓값으로 바꿔 반복 횟수만 구함
count = count > 0 ? count : -count;

for (int c = 0; c < count; c++)
{
    if (D >= 0) rotate45Clockwise();         // 양수면 시계 방향
    else        rotate45CounterClockwise();  // 음수면 반시계 방향
}
```
부호는 **방향 판정에만**, 크기는 **횟수에만** 쓴다.

## 5. 예제 손 추적 — N=3, D=90 (45도 시계 2회)

```
입력            1 2 3
                4 5 6
                7 8 9
```
`half = (3+1)/2 = 2`

### 1회차 (45도 시계)
`temp` 에서 읽는 네 줄:

| 줄 | 값 |
|---|---|
| 가운데 행 `temp[2][*]` | `4 5 6` |
| 주대각선 `temp[i][i]` | `1 5 9` |
| 가운데 열 `temp[*][2]` | `2 5 8` |
| 부대각선 `temp[4-i][i]` | `7 5 3` ← **아래→위** 로 훑는다 |

쓰기:
```
① 행 → 주대각:  MAP[1][1]=4  MAP[2][2]=5  MAP[3][3]=6
② 주대각 → 열:  MAP[1][2]=1  MAP[2][2]=5  MAP[3][2]=9
③ 열 → 부대각:  MAP[1][3]=2  MAP[2][2]=5  MAP[3][1]=8
④ 부대각 → 행:  MAP[2][1]=7  MAP[2][2]=5  MAP[2][3]=3
```
```
결과            4 1 2
                7 5 3
                8 9 6
```

### 2회차 (같은 과정 반복)
```
최종            7 4 1
                8 5 2
                9 6 3
```

> 실행으로 검증한 값이다.
> ```bash
> printf '1\n3 90\n1 2 3\n4 5 6\n7 8 9\n' | ./a.out
> ```
> N=3에서는 십자+X자가 9칸을 전부 덮으므로 결과가 **전체 90도 회전과 우연히 일치**한다.
> N=5로 확인해야 "가장자리 네 칸은 제자리"라는 이 문제의 진짜 성격이 보인다.

## 6. 함정 / 예상 함정
- **★ 음수 각도.** `count = D / 45` 가 음수로 나온다. 부호는 방향 판정(`D >= 0`)에만 쓰고, 반복 횟수는 절댓값으로 바꾼다. 안 바꾸면 `for (c = 0; c < -2; c++)` 이 되어 **한 번도 안 돈다** — 출력이 입력 그대로 나오는 증상.
- **★ 부대각선을 훑는 방향.** 시계에서는 `temp[N-i+1][i]`, 반시계에서는 `temp[i][N-i+1]` 로 읽는다. 같은 대각선인데 **훑는 방향이 반대**다. 헷갈리면 위 손 추적의 `7 5 3` vs `3 5 7` 로 되짚는다.
- **네 줄이 중심에서 겹친다.** N이 홀수면 중심 칸 `[half][half]` 가 네 줄 모두에 속해 네 번 덮인다. `temp` 기준으로 읽으니 매번 같은 값이 들어가 무해하다 — **in-place 였다면 여기서 깨진다.**
- **`arr` 을 매 단계 재사용**한다. 단계 안에서 읽기를 다 끝낸 뒤 쓰기를 하므로 문제없지만, 읽기·쓰기를 한 루프로 합치면 깨진다.
- T-loop이므로 케이스마다 N이 바뀐다. 배열을 초기화하진 않지만 출력 범위가 새 N을 따라가므로 잔여값은 무해하다.

## 7. 백지 재현 체크리스트
- [ ] `copyMap(temp, MAP)` 을 회전 함수 **첫 줄**에 넣었는가
- [ ] `half = (N + 1) / 2` 로 가운데 인덱스를 잡았는가
- [ ] 주대각선 `[i][i]` / 부대각선 `[i][N-i+1]` 을 구분하는가
- [ ] 부대각선을 **어느 방향으로 훑을지**를 시계/반시계 각각 정했는가
- [ ] 음수 D에서 횟수를 절댓값으로 바꿨는가
- [ ] 네 줄의 이동 순서(행→주대각→열→부대각)를 시계/반시계 각각 쓸 수 있는가

## 8. 한 줄 요약
"전체를 돌리지 않는다. **십자와 X자, 네 줄만 순환 교대**시키는 45도 회전."
