## 1. 문제 요약
`N×N` 교실에 `N²` 명의 학생을 앉힌다. 각 학생은 **좋아하는 친구 4명**이 정해져 있다.

**학생을 주어진 순서대로** 한 명씩 앉히며, 자리는 다음 **우선순위**로 고른다.
1. **인접한 칸에 좋아하는 친구가 가장 많은** 자리
2. 같으면 **인접한 빈 칸이 가장 많은** 자리
3. 같으면 **행이 작은** 자리
4. 같으면 **열이 작은** 자리

모두 앉힌 뒤 **만족도 총합**을 구한다.

| 인접한 좋아하는 친구 수 | 점수 |
|---|---|
| 0 | 0 |
| 1 | 1 |
| 2 | 10 |
| 3 | 100 |
| 4 | 1000 |

## 2. 필요한 이론
→ [G10 순수 시뮬레이션](../../theory/G10_순수시뮬레이션.md)

**새 알고리즘이 없다.** [G09 색깔 폭탄](../G09/2021상오전2_색깔폭탄.md)과 **같은 패턴** — 다중 우선순위 비교다.

> ### ★★ 4항목 우선순위 → 비교 함수로 분리
> ```c
> // a 가 우선순위가 더 높으면 true
> bool isPriority(SEAT a, SEAT b)
> {
>     if (a.like  != b.like)  return a.like  > b.like;    // ① 친구 많이 (크게)
>     if (a.empty != b.empty) return a.empty > b.empty;   // ② 빈 칸 많이 (크게)
>     if (a.r     != b.r)     return a.r     < b.r;       // ③ 행 작게
>     return a.c < b.c;                                    // ④ 열 작게
> }
> ```
> **항목마다 방향이 다르다** (크게/크게/작게/작게).
> 인라인 `if` 로 쓰면 반드시 틀린다 — **함수로 빼는 것이 정석.**
>
> [색깔 폭탄](../G09/2021상오전2_색깔폭탄.md)의 `isPriority` 와 **완전히 같은 구조**다.

**[전투로봇](../G09/2018하오후2_전투로봇.md)의 "스캔 순서 = 우선순위" 트릭은 여기서 못 쓴다.**
③④(행·열 작게)는 스캔 순서로 되지만, ①②(크게)는 방향이 반대이기 때문.

## 3. 코드 흐름
```
main()
 └ T-loop:
      input()          N, student[] (앉힐 순서), love[][] (좋아하는 관계)
      simulate()       ★ 한 명씩 자리 배정
      printf(getAnswer())

simulate():
   for i in 0..N²-1:
      index = student[i]
      wanted = 초기값 (우선순위 반대 방향)
      for r, c 전체:
         if (이미 앉은 자리) continue
         tmp = getSeatInfo(index, r, c)
         if (isPriority(tmp, wanted)) wanted = tmp
      MAP[wanted.r][wanted.c] = index
```

## 4. 핵심 코드

### 관계를 인접 행렬로
```c
int student[MAX * MAX];              // 앉힐 순서
bool love[MAX * MAX][MAX * MAX];     // love[a][b] = a가 b를 좋아함

// input() 에서
scanf("%d %d %d %d %d", &num, &one, &two, &three, &four);
student[i] = num;
love[num][one] = love[num][two] = love[num][three] = love[num][four] = true;
```

**`love` 가 `N² × N²` 인접 행렬**이다. `N ≤ 20` 이면 `400 × 400` = 16만 bool — 충분히 작다.
[G03 인접 행렬](../../theory/G03_DFS_BFS기초.md)과 같은 발상. **"좋아하는지"를 `O(1)` 로 판정**하려는 것.

> ⚠️ **관계가 단방향**이다. `love[a][b]` 와 `love[b][a]` 는 다르다.
> 만족도 계산에서 **누구 기준으로 세는지**를 정확히 해야 한다 (→ §6).

### 테두리 sentinel
```c
// 전체를 WALL 로 채우고
for (int r = 0; r <= N + 1; r++)
    for (int c = 0; c <= N + 1; c++)
        MAP[r][c] = WALL;

// 내부만 0(빈 자리)로
for (int r = 1; r <= N; r++)
    for (int c = 1; c <= N; c++)
        MAP[r][c] = 0;
```

**`WALL(-1)` 로 테두리를 두르면** 인접 검사에서 범위 체크가 사라진다.
`MAP` 값 규약: `-1` = 벽, `0` = 빈 자리, `1 이상` = 학생 번호.

### 자리 정보 수집
```c
struct SEAT
{
    int like;    // 주변의 좋아하는 친구 수
    int empty;   // 주변의 빈 자리 수
    int r, c;
};

SEAT getSeatInfo(int index, int r, int c)
{
    SEAT ret = { 0, 0, r, c };

    for (int i = 0; i < 4; i++)
    {
        int nr = r + dr[i], nc = c + dc[i];

        if (MAP[nr][nc] == WALL) continue;              // 벽
        if (MAP[nr][nc] == 0) { ret.empty++; continue; } // 빈 자리
        if (love[index][MAP[nr][nc]] == true) ret.like++; // 좋아하는 친구
    }

    return ret;
}
```

**세 갈래로 분기**한다: 벽 / 빈 자리 / 앉은 학생.
`love[index][이웃]` — **내가 이웃을 좋아하는지**를 본다.

### ★ 우선순위 초기값 — 각 항목마다 반대 방향
```c
SEAT wanted = { 0 };              // like = 0, empty = 0  (크게 이기므로 작게 시작)
wanted.r = wanted.c = INF;        // 행·열은 작게 이기므로 크게 시작
```

**네 필드를 각각 반대로 초기화**한다.
- `like`, `empty` → **크면 이김** → `0` 으로 시작
- `r`, `c` → **작으면 이김** → `INF` 로 시작

> 하나라도 틀리면 첫 후보가 채택되지 않거나 잘못 채택된다.
> [색깔 폭탄](../G09/2021상오전2_색깔폭탄.md)에서도 같은 함정이 나온다.

### 배정
```c
for (int r = 1; r <= N; r++)
{
    for (int c = 1; c <= N; c++)
    {
        if (MAP[r][c] != 0) continue;          // ★ 빈 자리만

        SEAT tmp = getSeatInfo(index, r, c);
        if (isPriority(tmp, wanted) == true) wanted = tmp;
    }
}

MAP[wanted.r][wanted.c] = index;               // 앉힌다
```

**격자 전체를 훑어 최선을 고른다.** `N²` 명 × `N²` 칸 × 4방향 = `N⁴ × 4`.
`N = 20` 이면 `160만 × 4 = 640만` — 여유롭게 통과.

### 만족도 — 룩업 테이블
```c
int getAnswer()
{
    int board[5] = { 0, 1, 10, 100, 1000 };    // ★ 점수표
    int score = 0;

    for (int r = 1; r <= N; r++)
    {
        for (int c = 1; c <= N; c++)
        {
            int index = MAP[r][c];
            int count = 0;

            for (int i = 0; i < 4; i++)
            {
                int nr = r + dr[i], nc = c + dc[i];

                if (MAP[nr][nc] == WALL) continue;
                if (love[index][MAP[nr][nc]] == true) count++;
            }

            score += board[count];             // ★ if/else 사슬 대신 배열
        }
    }

    return score;
}
```

**`board[5]` 룩업 테이블**이 `if/else if` 사슬을 대체한다.
소스에는 주석 처리된 `if/else` 버전이 남아 있다 — **배열 쪽이 짧고 실수가 적다.**

> `count` 는 `0~4` 이므로 배열 크기 5면 충분하다.

## 5. 예제 손 추적

### 우선순위 비교
```
후보 A: like=2, empty=1, r=3, c=1
후보 B: like=2, empty=3, r=1, c=1

isPriority(A, B):
  like 같음 (2 == 2)          → 다음
  empty 다름 (1 != 3)         → return 1 > 3 = false

→ B 우선   ★ 빈 칸이 더 많은 쪽
```

```
후보 C: like=2, empty=3, r=5, c=2
후보 B: like=2, empty=3, r=1, c=1

isPriority(C, B):
  like, empty 같음            → 다음
  r 다름 (5 != 1)             → return 5 < 1 = false

→ B 우선   ★ 행이 작은 쪽
```

### 초기값이 왜 반대 방향이어야 하는가
```
wanted 초기: like=0, empty=0, r=INF, c=INF

첫 후보 tmp: like=0, empty=0, r=1, c=1
isPriority(tmp, wanted):
  like 같음 (0 == 0)
  empty 같음 (0 == 0)
  r 다름 (1 != INF) → return 1 < INF = true ✓ → 채택
```
**`r` 을 `0` 으로 초기화했다면** `1 < 0` 이 거짓이라 **첫 후보가 채택되지 않는다.**

### 자리 정보
```
격자 (WALL 테두리 생략)
   0   5   0
   3  [?]  0        ← 여기에 index=7 을 앉히려 함
   0   0   0

love[7][5] = true,  love[7][3] = false

이웃 검사:
  위 (5):  학생 → love[7][5] = true  → like++
  아래 (0): 빈 자리 → empty++
  왼쪽 (3): 학생 → love[7][3] = false → 아무것도 안 함
  오른쪽 (0): 빈 자리 → empty++

결과: like=1, empty=2
```

### 만족도
```
학생 7 주변에 좋아하는 친구가 2명
→ board[2] = 10점
```

## 6. 함정 / 예상 함정
- **★★ 우선순위 비교 방향을 섞음.** `like` 크게 / `empty` 크게 / `r` 작게 / `c` 작게. **비교 함수로 분리.**
- **★★ 우선순위 초기값을 한 방향으로.** 네 필드를 **각각 반대로** 초기화.
- **★★ `love` 의 방향.** 단방향 관계다. 만족도는 **`love[자기][이웃]`** 으로 센다 — 이웃이 나를 좋아하는지가 아니다.
- **★ 빈 자리 검사 누락.** `MAP[r][c] != 0` 이면 이미 앉은 자리라 후보가 아니다.
- **★ 테두리 `WALL` 초기화 누락.** 인접 검사에서 범위를 벗어난다.
- **★ 앉힐 순서를 격자 순서로 착각.** **`student[]` 배열의 순서**대로 앉힌다. 학생 번호순이 아니다.
- **★ 점수를 `count` 그대로 더함.** `0/1/10/100/1000` 룩업 테이블이 필요하다.
- **`love` 배열 크기.** `N² × N²` — `N=20` 이면 `400×400`. `bool` 이라 16만 바이트, 괜찮다.
- **T-loop 마다 `MAP`, `love`, `student` 초기화 누락.** 이 코드는 `input()` 안에서 `love` 를 리셋한다.

## 7. 백지 재현 체크리스트
- [ ] 4항목 우선순위를 **비교 함수로 분리**했는가
- [ ] 각 항목의 **방향(크게/작게)** 을 정확히 쓰는가
- [ ] **초기값을 각 항목 반대 방향**으로 잡았는가
- [ ] `love` 를 **인접 행렬**로 두고 `O(1)` 판정하는가
- [ ] `love` 가 **단방향**임을 알고 `love[자기][이웃]` 으로 세는가
- [ ] 테두리를 **`WALL`** 로 초기화했는가
- [ ] 빈 자리(`MAP == 0`)만 후보로 삼는가
- [ ] **`student[]` 순서**대로 앉히는가
- [ ] 점수를 **룩업 테이블**로 변환하는가
