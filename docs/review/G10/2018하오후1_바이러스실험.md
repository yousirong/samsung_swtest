## 1. 문제 요약
N×N 격자에서 K년 동안 바이러스 실험을 진행한다.

각 칸에는 **현재 양분(`food`)**, **겨울마다 추가되는 양분(`MAP`)**, **여러 개의 바이러스(각각 나이)** 가 있다.
초기 양분은 모든 칸에서 **5**.

**1년 = 네 계절**
| 계절 | 규칙 |
|---|---|
| **봄** | **어린 바이러스부터** 자기 나이만큼 양분을 먹고 나이 +1. 양분이 부족하면 그 바이러스는 죽는다 |
| **여름** | 죽은 바이러스가 **`나이 / 2`** 만큼 양분으로 환원 |
| **가을** | 나이가 **5의 배수**인 바이러스가 **8방향**으로 나이 1짜리를 번식 |
| **겨울** | 각 칸에 `MAP[r][c]` 만큼 양분 추가 |

K년 후 **살아남은 바이러스 수**를 출력한다.

## 2. 필요한 이론
→ [G10 순수 시뮬레이션 — 계절 루프](../../theory/G10_순수시뮬레이션.md)

**새 알고리즘이 없다.** 대신 **자료구조 선택**이 이 문제의 전부다.

> ### ★★ 핵심: 칸마다 덱(deque)을 둔다
> ```c
> int virus[MAX][MAX][MAX_VIRUS];   // virus[r][c][i] = i번째 바이러스의 나이
> int front[MAX][MAX];              // 각 칸 덱의 앞
> int back[MAX][MAX];               // 각 칸 덱의 뒤
> ```
> **왜 덱인가**
> - **봄**: 앞(어린 쪽)부터 꺼내 처리 → `front` 전진
> - **가을**: 나이 1짜리를 **앞에** 삽입 → `front` 후퇴 (가장 어리므로)
> - **봄 생존자**: 뒤에 다시 append → `back` 전진
>
> **양쪽에서 삽입·삭제가 일어난다** → [G02 21번 덱](../G02/21_BOJ_10866_덱.md)이 그대로 필요하다.
> 그리고 **`OFFSET` 으로 중앙에서 시작**하는 것까지 똑같다.

## 3. 코드 흐름
```
main()
 └ input()                 N, M, K, MAP, food=5, front=back=OFFSET, 초기 바이러스
   for time in 0..K-1:
      step1_2()            봄 + 여름 (한 함수에서)
      step3()              가을
      step4()              겨울
   printf(getAnswer())     살아남은 바이러스 수
```

**함수 하나 = 계절 하나.** [G10 이론](../../theory/G10_순수시뮬레이션.md)의 "규칙 번호와 함수를 1:1 대응" 원칙 그대로.

## 4. 핵심 코드

### 덱 초기화 — 중앙에서 시작
```c
#define MAX_VIRUS (100000)
#define OFFSET    (10000)

// 각 칸의 deque 시작 위치를 OFFSET으로 맞춰 둔다.
// 앞/뒤 양쪽 삽입이 가능하도록 중간에서 시작
for (int r = 1; r <= N; r++)
    for (int c = 1; c <= N; c++)
        front[r][c] = back[r][c] = OFFSET;

// 초기 바이러스는 뒤쪽(back)에 순서대로 삽입
int& virusCount = back[r][c];
virus[r][c][virusCount++] = age;
```

**`OFFSET = 10000`** 만큼 왼쪽 여유를 둔다. 가을마다 `front` 가 감소하므로 필요하다.
[G02 덱](../G02/21_BOJ_10866_덱.md)의 `front = back = OFFSET` 과 완전히 같은 발상.

### ★★ 봄 + 여름 — 한 루프에서 이어서
```c
void step1_2()
{
    for (int r = 1; r <= N; r++)
    {
        for (int c = 1; c <= N; c++)
        {
            int start = front[r][c];
            int end   = back[r][c];
            int& fr = front[r][c];      // ★ 참조로 잡아 직접 갱신
            int& bk = back[r][c];
            int t;

            // 봄: 살아남는 바이러스 처리
            for (t = start; t < end; t++)
            {
                if (virus[r][c][t] <= food[r][c])       // 먹을 수 있으면
                {
                    food[r][c] -= virus[r][c][t];        // 양분 소비
                    virus[r][c][t]++;                    // 나이 +1
                    fr++;                                // 앞에서 제거
                    virus[r][c][bk++] = virus[r][c][t];  // ★ 뒤에 다시 저장
                }
                else break;                              // ★ 이후는 전부 죽음
            }

            // 여름: 죽은 바이러스 양분 환원
            for (; t < end; t++)
            {
                food[r][c] += (virus[r][c][t] / 2);
                fr++;
            }
        }
    }
}
```

**세 가지 설계가 맞물린다.**

**① `break` 하나로 "이후는 전부 죽음"이 성립한다.**
바이러스가 **나이순(어린 것부터)** 으로 정렬돼 있으므로, 한 마리가 못 먹으면 **그보다 나이 많은 뒤쪽은 당연히 못 먹는다.**
정렬이 깨지면 이 논리가 무너진다 (→ §6 ⚠️).

**② 살아남은 것을 `bk++` 로 뒤에 다시 넣는다.**
`bk` 는 `end` 부터 시작하고 `t` 는 `start < end` 이므로 **쓰는 자리가 읽는 자리를 절대 추월하지 않는다.**
그리고 처리 순서가 어린 것부터이므로 **재배치 후에도 나이순이 유지**된다.

**③ 여름 루프가 `t` 를 이어받는다.**
`for (; t < end; t++)` — 봄 루프가 `break` 한 지점부터 시작한다. `t` 를 루프 밖에서 선언한 이유.

> **`int& fr = front[r][c];`** — C++의 참조. 배열 접근을 짧게 쓰려는 것이지만, **C 스타일 파일에서 유일하게 C++ 문법이 섞인 곳**이다.
> 순수 C로 쓰려면 지역 변수에 담았다가 마지막에 되쓰면 된다.

### 가을 — 앞쪽에 나이 1 삽입
```c
void step3()
{
    for (int r = 1; r <= N; r++)
    {
        for (int c = 1; c <= N; c++)
        {
            int start = front[r][c];
            int end   = back[r][c];

            for (int t = start; t < end; t++)
            {
                if (virus[r][c][t] % 5 != 0) continue;   // 5의 배수만 번식

                for (int i = 0; i < 8; i++)              // ★ 8방향
                {
                    int nr = r + dr[i];
                    int nc = c + dc[i];

                    if (nr < 1 || nc < 1 || nr > N || nc > N) continue;

                    // front를 하나 줄이면서 앞쪽에 나이 1 삽입
                    int& fr = front[nr][nc];
                    virus[nr][nc][--fr] = 1;             // ★ 앞에 넣는다
                }
            }
        }
    }
}
```

**★ `--fr` 로 앞에 삽입**하는 것이 핵심이다. 나이 1이 가장 어리므로 **덱의 맨 앞**이어야 봄의 `break` 논리가 유지된다.

> **가을에 `start`/`end` 를 미리 떠 둔 것**도 중요하다.
> 번식으로 `front[nr][nc]` 가 바뀌는데, **현재 칸의 순회 범위는 고정**되어야 한다.
> 자기 칸에 번식이 일어나도(대각선 이웃이 자기 자신일 수는 없지만) 안전하다.

**8방향**이라 `dr/dc` 가 8개다 — [G05 35번 섬의 개수](../G05/35_BOJ_4963_섬의개수.md)와 같은 배열.

### 겨울 + 답
```c
void step4()
{
    for (r, c) food[r][c] += MAP[r][c];
}

int getAnswer()
{
    int sum = 0;
    for (r, c) sum += (back[r][c] - front[r][c]);   // ★ 덱 크기 = 개수
    return sum;
}
```
**`back - front` 가 그 칸의 바이러스 수**다. [G02 덱](../G02/21_BOJ_10866_덱.md)의 `size` 와 동일.

## 5. 예제 손 추적

### 봄의 `break` 논리
```
칸 (1,1): 양분 5, 바이러스 [2, 4]  (어린 것부터 정렬)

t=0: 나이 2 <= 양분 5 ✓
     food = 5 - 2 = 3,  나이 → 3,  뒤에 재삽입
t=1: 나이 4 <= 양분 3 ✗  →  break

여름: t=1부터
     food += 4/2 = 2  →  food = 5
     
결과: 살아남은 바이러스 [3], 양분 5
```

### 가을 — 5의 배수만
```
나이 3  →  3 % 5 != 0  →  번식 안 함
나이 5  →  5 % 5 == 0  →  8방향 번식 ✓
나이 10 →  10 % 5 == 0 →  번식 ✓
```

### 덱 인덱스 추적
```
초기:  front = back = 10000 (OFFSET)
       바이러스 2마리 삽입 → back = 10002
       virus[10000]=2, virus[10001]=4

봄:    t=10000: 생존 → fr=10001, virus[10002]=3, bk=10003
       t=10001: 죽음 → break
여름:  t=10001: fr=10002
       
결과:  front=10002, back=10003  →  크기 1
       virus[10002] = 3  ✓
```
**`bk` 가 `t` 를 추월하지 않는다**는 것이 여기서 보인다 (`t=10001` 일 때 `bk=10003`).

### 가을 삽입
```
이웃 칸 (1,2): front=10000, back=10000 (비어있음)
번식 → virus[1][2][--10000] = virus[1][2][9999] = 1
       front = 9999, back = 10000  →  크기 1
```
**`front` 가 `OFFSET` 아래로 내려간다.** 그래서 `OFFSET` 여유가 필요하다.

## ⚠️ 6-1. 검증된 발견 — 입력이 나이순 정렬되어 있다고 가정한다

봄의 `break` 는 **바이러스가 어린 것부터 정렬돼 있다**는 전제 위에 있다.
- **가을 삽입**은 나이 1을 앞에 넣으므로 정렬을 유지한다 ✓
- **봄 재배치**도 순서를 보존한다 ✓
- **초기 입력**은? → `back` 에 **읽은 순서 그대로** 넣는다. **정렬하지 않는다.**

소스 전체에 정렬 코드가 없다.
```bash
grep -nE 'sort|swap' 코드트리_2018_하반기오후1번_바이러스실험.cpp   # 결과 없음
```

**실제로 답이 갈리는지 실험했다.**
```bash
# N=2, M=2, K=1, 겨울양분 0, 같은 칸 (1,1)에 나이 2와 4 (초기 양분 5)
printf '2 2 1\n0 0\n0 0\n1 1 2\n1 1 4\n' | ./a.out   # 어린 것 먼저 →  1
printf '2 2 1\n0 0\n0 0\n1 1 4\n1 1 2\n' | ./a.out   # 나이 든 것 먼저 →  4
```

**같은 입력인데 줄 순서만 바꿔서 답이 `1` 과 `4` 로 갈린다.**

**왜 그런가**
```
[2, 4] 순서 (정렬됨, 올바름)
  나이2 먹음 (5→3), 생존 나이3
  나이4 > 3 → 죽음, 양분 +2
  → 나이 3짜리 1마리, 가을에 3 % 5 != 0 → 번식 없음 → 답 1 ✓

[4, 2] 순서 (정렬 안 됨)
  나이4 먹음 (5→1), 생존 나이5
  나이2 > 1 → 죽음, 양분 +1
  → 나이 5짜리 1마리, 가을에 5 % 5 == 0 → 8방향 번식!
     (1,1) 이웃 중 격자 안: (1,2),(2,1),(2,2) 3곳
  → 답 1 + 3 = 4 ✗
```

> **규칙은 "어린 바이러스부터 양분을 먹는다"** 이므로 **정답은 `1`** 이다.
> 채점을 통과한 것은 **테스트 데이터가 나이순으로 주어졌거나, 한 칸에 초기 바이러스가 하나뿐이었을 가능성**이 높다.

**복습할 때 할 일**
```c
// input() 마지막에 각 칸의 덱을 나이 오름차순으로 정렬 (선택정렬)
for (int r = 1; r <= N; r++)
    for (int c = 1; c <= N; c++)
        for (int i = front[r][c]; i < back[r][c] - 1; i++)
            for (int k = i + 1; k < back[r][c]; k++)
                if (virus[r][c][i] > virus[r][c][k])
                { int t = virus[r][c][i]; virus[r][c][i] = virus[r][c][k]; virus[r][c][k] = t; }
```
M이 최대 `N²` 수준이므로 선택정렬로 충분하다.

## 6. 함정 / 예상 함정
- **★★ 초기 입력을 나이순 정렬하지 않음.** 위 §6-1. **검증된 문제.**
- **★★ 봄에서 살아남은 것을 앞에 다시 넣음.** **뒤(`bk++`)** 여야 한다. 앞에 넣으면 아직 안 읽은 데이터를 덮는다.
- **★★ 가을 번식을 뒤에 삽입.** 나이 1은 **가장 어리므로 앞(`--fr`)**. 뒤에 넣으면 정렬이 깨져 봄의 `break` 가 틀린다.
- **★ 가을 순회 범위를 실시간으로 읽음.** `start`/`end` 를 **미리 떠 둬야** 번식으로 늘어난 것을 그 해에 또 처리하지 않는다.
- **★ 봄과 여름을 분리된 루프로.** 여름은 봄이 `break` 한 `t` 부터 이어받는다. `t` 를 루프 밖에서 선언.
- **★ 여름 환원이 `나이 / 2`** (정수 나눗셈, 버림). 죽기 **전** 나이 기준.
- **★ 8방향인데 4방향 배열 사용.** 가을 번식은 대각선 포함.
- **`OFFSET` 부족.** 가을마다 `front` 가 감소한다. K년 × 번식량을 감당할 여유 필요.
- **`MAX_VIRUS` 부족.** 바이러스가 지수적으로 늘 수 있다. 넉넉히.
- **초기 양분이 5 고정**임을 잊고 입력에서 읽으려 함.
- **T-loop 마다 `food`, `front`, `back`, `virus` 초기화 누락.**

## 7. 백지 재현 체크리스트
- [ ] 칸마다 **덱**을 두고 `OFFSET` 중앙에서 시작하는가
- [ ] **초기 입력을 나이순 정렬**하는가 (⚠️ 원본 소스에 없음)
- [ ] 봄에서 `break` 가 성립하는 **전제(정렬)** 를 설명할 수 있는가
- [ ] 봄 생존자를 **뒤(`bk++`)** 에 재삽입하는가
- [ ] 가을 번식을 **앞(`--fr`)** 에 삽입하는가
- [ ] 가을 순회 범위를 **미리 떠 두는가**
- [ ] 여름이 봄의 `t` 를 이어받는가
- [ ] 번식이 **8방향**인가, 5의 배수만인가
- [ ] 답이 **`back - front` 의 합**인가

## 8. 한 줄 요약
"**칸마다 덱** — 봄은 앞에서 꺼내고, 생존자는 뒤에, 가을 새싹은 앞에. **정렬 전제**가 `break` 를 지탱한다."
