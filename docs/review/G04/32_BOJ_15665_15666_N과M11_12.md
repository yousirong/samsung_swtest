## 1. 문제 요약
| 문제 | 성격 | 내용 |
|---|---|---|
| **15665** N과 M(11) | **중복순열** | 입력값 중 **중복 허용**, 길이 M 수열. 순서 O |
| **15666** N과 M(12) | **중복조합** | 입력값 중 중복 허용, **비내림차순** 수열. 순서 X |

두 문제 모두 **입력에 같은 값이 여러 번 들어올 수 있고, 같은 수열은 한 번만 출력**해야 한다.

## 2. 필요한 이론
→ [G04 경우의 수 — 중복 입력값 처리 (가)](../../theory/G04_경우의수.md)

이 문제의 핵심은 재귀 구조가 아니라 **입력 전처리**다.

> **★ 처방: 서로 다른 값만 추려서 쓴다.**
>
> 같은 값을 **몇 번이든 뽑아도 되는** 유형(중복 허용)이므로, 입력에 `9` 가 몇 개인지는 **아무 의미가 없다.** `9` 가 있다는 사실만 알면 된다.
> 중복을 제거한 뒤 정렬하면, 재귀는 [28번](28_BOJ_15651_15656_중복순열.md)·[29번](29_BOJ_15652_15657_중복조합.md)과 완전히 같아진다.

### [30번 15663](30_BOJ_15649_15654_15663_순열.md)과 처방이 다르다 — 이게 이 문제의 학습 포인트
| | 15663 (순열, 중복 **불가**) | 15665/15666 (중복 **허용**) |
|---|---|---|
| 같은 값을 몇 번 쓸 수 있나 | **입력에 있는 개수만큼** | **무제한** |
| 그래서 필요한 것 | `possible[]` 개수 집계 + `visit` **카운터** | **종류만** 추리기 (`check[]`) |
| `9 7 9`, M=2 에서 `9 9` | 가능 (9가 2개라서) | 가능 (무제한이라서) |
| `7 7` | **불가** (7이 1개) | **가능** |

**"몇 개 있는지가 답에 영향을 주는가"** 로 두 처방을 가른다.

## 3. 코드 흐름
```
main()
 └ scanf(N, M)
   입력 받으며 중복 제거:
      if (check[value] == 0) { check[value] = 1; number[++cnt] = value; }
   N = cnt                          ← 서로 다른 값 개수로 갱신
   정렬 (선택 정렬)
   15665: DFS(0)         ← 중복순열
   15666: DFS(0, 1)      ← 중복조합
```

## 4. 핵심 코드

### ★ 중복 제거 — `check[]` 로 종류만 남긴다
```c
bool check[10000 + 100];   // 어떤 값이 이미 number[]에 들어갔는지 확인
int number[MAX];           // 중복 제거 후 남긴 서로 다른 값들

// 입력: 9 7 9  →  중복 제거 후: 7 9
```
`check` 크기가 `10000 + 100` 인 이유: **값 자체를 인덱스로** 쓰기 때문이다. 문제 조건상 입력값이 10000 이하다.
(값 범위가 크면 이 방법을 못 쓰고, 정렬 후 인접 비교로 중복을 제거해야 한다.)

### 15665 — 중복순열 재귀 (28번과 동일)
```c
void DFS(int depth)
{
    if (depth == M) { printCases(); return; }

    // 현재 자리에 서로 다른 값들 중 하나를 선택
    for (int i = 1; i <= N; i++)
    {
        num_of_cases[depth] = number[i];
        DFS(depth + 1);            // ★ start 없음, visit 없음
    }
}
```

### 15666 — 중복조합 재귀 (29번과 동일)
```c
void DFS(int depth, int start)
{
    if (depth == M) { printCases(); return; }

    for (int i = start; i <= N; i++)
    {
        num_of_cases[depth] = number[i];
        DFS(depth + 1, i);         // ★ i (i+1 아님)
    }
}
```

**재귀는 새로울 게 하나도 없다.** 전처리에서 중복을 없앴기 때문에 이후는 표준 형태 그대로다. 이것이 좋은 설계다 — **복잡함을 한 곳(입력)에 몰아넣는다.**

### 정렬
```c
for (int i = 1; i <= N - 1; i++)
    for (int k = i + 1; k <= N; k++)
        if (number[i] > number[k]) { /* swap */ }
```
사전순 출력을 위해 필수. 15666은 **비내림차순 수열**의 전제이기도 하다.

## 5. 예제 손 추적 — 입력 `9 7 9`, `M = 2`

### 전처리
```
입력       9 7 9
check[9]=0 → number[1] = 9, check[9]=1
check[7]=0 → number[2] = 7, check[7]=1
check[9]=1 → 이미 있음, 건너뜀        ★ 두 번째 9는 버려진다

중복 제거   number = {9, 7},  N = 2
정렬 후     number = {7, 9}
```

### 15665 (중복순열) — `2^2 = 4`가지
```
depth 0, i=1(값 7) → depth 1: i=1 → [7 7]
                              i=2 → [7 9]
depth 0, i=2(값 9) → depth 1: i=1 → [9 7]
                              i=2 → [9 9]
```
```
출력   7 7
       7 9
       9 7
       9 9
```

> 실행으로 검증했다 (BOJ 15665 예제 출력과 일치).
> ```bash
> printf '3 2\n9 7 9\n' | python3 docs/split.py 32_BOJ_15665_15666_N과M11_12.cpp 15665
> ```

### 15666 (중복조합) — 같은 입력이면 3가지
```
출력   7 7
       7 9
       9 9        ★ 9 7 이 사라짐 (내림차순이라)
```

### ★ 15663과 나란히 — 같은 입력 `9 7 9`, M=2
| | 15663 (순열·중복불가) | 15665 (중복순열) |
|---|---|---|
| `7 7` | ✗ (7이 1개) | **✓** |
| `9 9` | ✓ (9가 2개) | ✓ |
| `7 9` | ✓ | ✓ |
| `9 7` | ✓ | ✓ |
| **개수** | **3** | **4** |

**차이는 `7 7` 하나**다. 그리고 그 하나가 두 처방이 다른 이유 전부다.
- 15663: `7` 은 입력에 1개 → 카운터가 1에서 막힘
- 15665: 중복 허용 → 개수 무관, 종류만 있으면 무한정

## 6. 함정 / 예상 함정
- **★★ 처방을 [15663](30_BOJ_15649_15654_15663_순열.md)과 뒤바꿈.** 중복 허용 유형에 카운터를 쓰면 `7 7` 이 빠지고, 중복 불가 유형에 `check[]` 만 쓰면 `7 7` 이 잘못 나온다. **"개수가 답에 영향을 주는가"** 로 판단한다.
- **★ `N` 을 갱신하지 않음.** 중복 제거 후 서로 다른 값 개수로 `N` 을 바꿔야 한다. 원래 `N` 그대로 두면 `number[]` 의 빈 자리(0)까지 순회한다.
- **★ 정렬 누락.** 사전순 출력이 깨진다. `9 7 9` 는 정렬 안 하면 `9 9` 가 먼저 나온다.
- **`check[]` 크기를 `MAX` 로 잡음.** 값 자체가 인덱스라 **값의 최댓값 + 여유**여야 한다. `MAX (7+3)` 으로 잡으면 `check[9]` 조차 범위 밖.
- **음수나 큰 값 입력.** 이 문제는 1~10000 이라 배열 인덱싱이 되지만, 값 범위가 넓으면 이 방법을 못 쓴다. 대안: **정렬 후 인접 원소 비교**로 중복 제거.
- **15665와 15666의 재귀를 뒤바꿈** — `DFS(depth+1)` vs `DFS(depth+1, i)`.
- 한 파일에 두 프로그램 — 그대로 컴파일 불가.

## 7. 백지 재현 체크리스트
- [ ] **"개수가 답에 영향을 주는가"** 로 두 처방을 가를 수 있는가
- [ ] 중복 허용 유형에서는 **종류만** 추리면 되는 이유를 아는가
- [ ] `check[]` 인덱스가 **값 자체**임을, 그래서 크기가 값 범위임을 아는가
- [ ] 중복 제거 후 `N` 을 갱신했는가
- [ ] 정렬을 넣었는가
- [ ] 15665(중복순열)와 15666(중복조합)의 재귀 차이를 아는가
- [ ] 같은 입력에서 15663과 15665의 결과 차이(`7 7`)를 설명할 수 있는가
