## 1. 문제 요약
| 문제 | 내용 |
|---|---|
| **15651** N과 M(3) | `1 ~ N` 중에서 **중복을 허용해** M개를 골라 만든 모든 수열 출력 |
| **15656** N과 M(7) | `1~N` 대신 **입력으로 주어진 N개의 값**을 사용. 나머지는 동일 |

두 문제 모두 **순서가 다르면 다른 수열**이다. `1 2` 와 `2 1` 은 둘 다 출력된다.

## 2. 필요한 이론
→ [G04 경우의 수 — 4종 구분표](../../theory/G04_경우의수.md)

**4종 중 가장 제약이 없는 형태.** [27번](27_경우의수_순열_조합_중복순열_중복조합.md) ①블록의 3중 for를 재귀로 옮긴 것이다.

| 축 | 값 |
|---|---|
| 순서 | **O** (다르면 다른 경우) |
| 중복 | **O** (같은 값 여러 번 가능) |

> **그래서 `visit` 도 `start` 도 필요 없다.** 매 자리에서 `1 ~ N` 전부를 그냥 시도한다.
> 개수 = `N^M`.

## 3. 코드 흐름
```
main()
 └ scanf(N, M)
   DFS(0)              ← 인자가 depth 하나뿐
   
DFS(depth):
   if (depth == M) { printCases(); return; }
   for i in 1..N:
      num_of_cases[depth] = i
      DFS(depth + 1)
```

## 4. 핵심 코드

### 15651 — 최소 형태
```c
// DFS로 중복 순열 생성
void DFS(int depth)
{
    // 길이 M 수열 완성 시 출력
    if (depth == M)
    {
        printCases();
        return;                 // ★ return 필수
    }

    for (int i = 1; i <= N; i++)
    {
        num_of_cases[depth] = i;

        // 중복 허용이므로 visit 체크 없이 바로 다음 자리로 진행
        DFS(depth + 1);
    }
}
```

**이것이 백트래킹의 최소 골격이다.** 여기에 조건을 하나씩 붙이면 나머지 3종이 나온다.
- `start` 를 넘기면 → [중복조합](29_BOJ_15652_15657_중복조합.md) / [조합](31_BOJ_15650_15655_15664_조합.md)
- `visit` 을 붙이면 → [순열](30_BOJ_15649_15654_15663_순열.md)

### `num_of_cases[depth]` — 되돌릴 필요가 없다
```c
num_of_cases[depth] = i;    // 다음 반복에서 어차피 덮어써진다
DFS(depth + 1);
// num_of_cases[depth] = 0;  ← 이런 복원은 불필요
```
`depth` 자리는 이 루프가 매번 새로 채운다. **복원이 필요한 것은 `visit` 뿐**이다 ([30번](30_BOJ_15649_15654_15663_순열.md)).

### 15656 — 입력값 사용 + 정렬
```c
for (int i = 1; i <= N; i++)
    scanf("%d", &number[i]);

// 사전순 출력을 위해 오름차순 정렬 (선택 정렬)
for (int i = 1; i <= N - 1; i++)
    for (int k = i + 1; k <= N; k++)
        if (number[i] > number[k]) { /* swap */ }
```
그리고 DFS 안에서 `num_of_cases[depth] = number[i]` 로 바뀐다.

> **정렬이 필수다.** 문제가 "사전순 증가 순서로 출력"을 요구하는데, DFS는 `i` 를 1부터 올리며 돌 뿐이다. `number[]` 가 정렬돼 있어야 그 순회가 곧 사전순이 된다.
> STL `sort` 가 없으므로 **선택 정렬을 직접 쓴다** — A형에서 반복되는 관용구.

## 5. 예제 손 추적 — `N=4, M=2` (15651)

`DFS(0)` 부터 재귀 전개. 트리로 보면 깊이 2, 각 노드에서 4갈래.

```
depth 0:  i=1 ──┬── depth 1: i=1 → [1 1] 출력
                ├──           i=2 → [1 2] 출력
                ├──           i=3 → [1 3] 출력
                └──           i=4 → [1 4] 출력
          i=2 ──┬── depth 1: i=1 → [2 1] 출력    ★ [1 2] 와 별개!
                └──           ...
          i=3 ...
          i=4 ...
```

| 순번 | 출력 | 순번 | 출력 |
|---|---|---|---|
| 1 | `1 1` | 9 | `3 1` |
| 2 | `1 2` | 10 | `3 2` |
| 3 | `1 3` | 11 | `3 3` |
| 4 | `1 4` | 12 | `3 4` |
| 5 | `2 1` | 13 | `4 1` |
| 6 | `2 2` | 14 | `4 2` |
| 7 | `2 3` | 15 | `4 3` |
| 8 | `2 4` | 16 | `4 4` |

**총 16가지 = `4^2`.**

두 가지가 눈에 띈다.
- `1 1` 이 있다 → **중복 허용**
- `1 2` 와 `2 1` 이 **둘 다** 있다 → **순서 구분**

> 실행으로 검증했다 (16가지).
> ```bash
> printf '4 2\n' | python3 docs/split.py 28_BOJ_15651_15656_중복순열.cpp 15651
> ```

## 6. 함정 / 예상 함정
- **★ 종료 조건 뒤 `return` 누락.** `printCases()` 만 하고 `return` 을 빼면 `depth` 가 M을 넘어 `num_of_cases[]` 범위 밖에 쓴다.
- **★ 15656에서 정렬 누락.** 사전순 출력이 깨진다. 입력이 이미 정렬되어 들어오는 예제로는 **안 걸린다**.
- **`num_of_cases` 를 복원하려 함.** 불필요하다. 복원이 필요한 건 `visit` 뿐이라는 걸 구분한다.
- **`i` 를 0부터 시작.** 1~N 이므로 `i = 1`. 15656은 `number[1..N]` 이라 역시 1부터.
- **탐색 공간.** `N^M` 이다. `N=7, M=7` 이면 `7^7 = 82만` — 통과. 하지만 출력이 82만 줄이라 I/O가 병목이 된다.
- **`MAX` 크기.** 문제 조건이 `N, M ≤ 7` 이라 `#define MAX (7 + 3)` 로 충분하다. 기출에 응용할 땐 다시 계산할 것.
- 한 파일에 15651·15656 두 프로그램이 있어 **그대로 컴파일하면 전역 중복 정의 오류**가 난다.

## 7. 백지 재현 체크리스트
- [ ] 중복순열이 왜 `visit` 도 `start` 도 필요 없는지 설명할 수 있는가
- [ ] `if (depth == M) { 출력; return; }` 을 빠뜨리지 않는가
- [ ] `num_of_cases[depth]` 는 복원이 불필요함을 아는가
- [ ] 개수가 `N^M` 임을 계산할 수 있는가
- [ ] 15656에서 **입력 정렬**이 필요한 이유를 아는가
- [ ] 선택 정렬을 STL 없이 쓸 수 있는가
- [ ] 이 골격에서 나머지 3종을 유도할 수 있는가
