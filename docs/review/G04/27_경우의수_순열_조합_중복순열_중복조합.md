# 27 — 경우의 수 4종 템플릿 (순열 · 조합 · 중복순열 · 중복조합)

| 항목 | 내용 |
|---|---|
| 유형 | G04 경우의 수 · 백트래킹 ★ **이 그룹의 출발점** |
| 소스 | [swtest/27_경우의수_순열_조합_중복순열_중복조합.cpp](../../../swtest/27_경우의수_순열_조합_중복순열_중복조합.cpp) |

## 1. 문제 요약
BOJ 문제가 아니다. **1~4 중에서 3개를 뽑는 네 가지 방법**을 3중 `for` 문으로 나란히 구현한 참고 파일이다.

| 블록 | 이름 | 예 |
|---|---|---|
| 1 | 중복순열 `4Π3` | `1 1 1`, `1 2 1` 가능 → 64가지 |
| 2 | 중복조합 `4H3` | `1 1 2` 만, `2 1 1` 은 같은 경우로 취급 |
| 3 | 조합 `4C3` | `1 2 3` 만, `1 1 2` 불가 |
| 4 | 순열 `4P3` | `1 2 3` 과 `3 2 1` 은 다른 경우 |

## 2. 필요한 이론
→ [G04 경우의 수 · 백트래킹](../../theory/G04_경우의수.md)

**이 파일부터 시작해야 하는 이유**: 28~31번은 이 네 패턴을 각각 재귀로 옮긴 것이다.
3중 `for` 문은 M=3 에 고정되어 실전에 못 쓰지만, **네 가지의 차이가 눈에 그대로 보인다.** 재귀로 넘어가기 전에 여기서 차이를 먼저 새긴다.

### 두 축
|  | 순서 O | 순서 X |
|---|---|---|
| **중복 O** | ① 중복순열 | ② 중복조합 |
| **중복 X** | ④ 순열 | ③ 조합 |

## 3. 코드 흐름
```
main()
 └ if (1) { 중복순열 }      ← 켜고 싶은 블록만 1로
   if (0) { 중복조합 }
   if (0) { 조합 }
   if (0) { 순열 }
```
`if (1)` / `if (0)` 으로 블록을 토글한다. 실행하려면 보고 싶은 블록만 `1` 로 바꾼다.

## 4. 핵심 코드 — 네 블록 나란히

### ① 중복순열 `4Π3` — 제약 없음
```c
for (int a = 1; a <= 4; a++)          // 첫 번째 자리
    for (int b = 1; b <= 4; b++)      // 두 번째 자리
        for (int c = 1; c <= 4; c++)  // 세 번째 자리
            printf("%d] %d %d %d\n", count++, a, b, c);
```
각 자리에 1~4가 전부 들어간다. `4 × 4 × 4 = 64`가지.

### ② 중복조합 `4H3` — `a ≤ b ≤ c`
```c
for (int a = 1; a <= 4; a++)
    for (int b = a; b <= 4; b++)      // ★ b는 a 이상
        for (int c = b; c <= 4; c++)  // ★ c는 b 이상
            printf(...);
```
**오름차순으로만 뽑아 순서를 없앤다.** `1 1 2` 는 나오지만 `1 2 1`, `2 1 1` 은 안 나온다.
같은 값 반복은 허용(`b = a` 부터).

### ③ 조합 `4C3` — `a < b < c`
```c
for (int a = 1; a <= 4; a++)
    for (int b = a + 1; b <= 4; b++)      // ★ a보다 커야
        for (int c = b + 1; c <= 4; c++)  // ★ b보다 커야
            printf(...);
```
**②에서 `a` → `a + 1` 로 바뀐 것뿐이다.** 이 `+1` 하나가 "같은 값 재사용 금지"를 만든다.
`4C3 = 4`가지.

### ④ 순열 `4P3` — `visit` 배열
```c
bool visit[5] = { 0 };   // 1~4 사용 여부 체크

for (int a = 1; a <= 4; a++)
{
    visit[a] = true;                          // a 사용 처리

    for (int b = 1; b <= 4; b++)
    {
        if (visit[b] == true) continue;       // 이미 쓴 숫자 건너뜀
        visit[b] = true;

        for (int c = 1; c <= 4; c++)
        {
            if (visit[c] == true) continue;
            printf(...);                       // a, b, c 모두 다름
        }

        visit[b] = false;   // ★ b 사용 해제
    }

    visit[a] = false;       // ★ a 사용 해제
}
```
순서가 중요하므로 범위는 항상 `1..4` 로 두고, **`visit` 으로만** 중복을 막는다.
`4P3 = 24`가지.

## 5. 예제 손 추적 — 네 블록의 출력 비교

같은 "1~4 중 3개"인데 결과가 이렇게 다르다.

### ① 중복순열 (64가지, 앞부분)
```
1] 1 1 1      5] 1 2 1      17] 2 1 1
2] 1 1 2      6] 1 2 2      ...
3] 1 1 3      7] 1 2 3      64] 4 4 4
4] 1 1 4      8] 1 2 4
```

### ② 중복조합 (20가지, 전체)
```
 1] 1 1 1     6] 1 2 3     11] 2 2 2     16] 2 4 4
 2] 1 1 2     7] 1 2 4     12] 2 2 3     17] 3 3 3
 3] 1 1 3     8] 1 3 3     13] 2 2 4     18] 3 3 4
 4] 1 1 4     9] 1 3 4     14] 2 3 3     19] 3 4 4
 5] 1 2 2    10] 1 4 4     15] 2 3 4     20] 4 4 4
```
> `1 2 1` 이 **없다.** `1 1 2` 로 이미 대표되기 때문 — 이게 "순서 X"의 의미.
> 전부 `a ≤ b ≤ c` 를 만족하는 것도 확인할 수 있다.

### ③ 조합 (4가지, 전체)
```
1] 1 2 3
2] 1 2 4
3] 1 3 4
4] 2 3 4
```
> ②에서 **같은 값이 겹친 것들이 전부 사라졌다.** `1 1 2`, `2 2 3` … 20 → 4.

### ④ 순열 (24가지, 앞부분)
```
1] 1 2 3      7] 2 1 3     13] 3 1 2     19] 4 1 2
2] 1 2 4      8] 2 1 4     ...          ...
3] 1 3 2      9] 2 3 1                  24] 4 3 2
4] 1 3 4     10] 2 3 4
5] 1 4 2     11] 2 4 1
6] 1 4 3     12] 2 4 3
```
> ③의 4가지 각각이 **순서를 바꿔 6가지씩** = 24. `4C3 × 3! = 4 × 6 = 24`.

### 개수 관계 정리
```
중복순열 64  ⊃  중복조합 20  ⊃  조합 4
                                조합 4 × 3! = 순열 24
```

> **위 출력은 전부 실제 실행으로 검증한 것이다.** 소스를 직접 고치지 않고 확인하려면 사본을 만든다.

## 6. 함정 / 예상 함정
- **★ ②와 ③의 차이가 `a` vs `a + 1` 뿐이다.** 이 `+1` 을 놓치면 중복조합과 조합이 뒤바뀐다. 재귀 버전에서도 `DFS(depth+1, i)` vs `DFS(depth+1, i+1)` 로 똑같이 나타난다 — **여기서 새겨두면 평생 안 헷갈린다.**
- **★ ④에서 `visit` 되돌림 누락.** `visit[b] = false` 를 빼면 `b` 로 쓴 숫자가 영영 막혀 출력이 급감한다. 재귀 버전의 백트래킹과 정확히 같은 실수.
- **`visit[5]`** 크기 — 1~4를 인덱스로 쓰므로 5칸(0번 미사용). 4칸으로 잡으면 `visit[4]` 가 범위 밖.
- **3중 for는 M=3 전용이다.** M이 입력으로 주어지면 못 쓴다. 그래서 [28~31번](28_BOJ_15651_15656_중복순열.md)의 재귀가 필요하다 — 이 파일은 **개념 확인용**이지 실전용이 아니다.
- **`if (1)` 을 여러 개 켜면** 출력이 섞인다. 한 번에 하나만.

## 7. 백지 재현 체크리스트
- [ ] 네 가지를 **순서 O/X × 중복 O/X** 표로 분류할 수 있는가
- [ ] "순서를 없애려면 오름차순으로만 뽑는다"를 설명할 수 있는가
- [ ] 중복조합 `b = a` / 조합 `b = a + 1` — **`+1` 의 의미**를 아는가
- [ ] 순열에서 `visit` 을 **되돌려야** 하는 이유를 아는가
- [ ] `4Π3 = 64`, `4H3 = 20`, `4C3 = 4`, `4P3 = 24` 를 계산할 수 있는가
- [ ] 이 4종을 **재귀로** 옮길 수 있는가 → [G04 이론 카드](../../theory/G04_경우의수.md)의 스위치 표

## 8. 한 줄 요약
"**순서를 없애려면 오름차순, 중복을 없애려면 `+1` 또는 `visit`.** 3중 for가 곧 재귀의 뼈대다."
