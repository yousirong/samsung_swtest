## 1. 문제 요약
| 문제 | 내용 |
|---|---|
| **15652** N과 M(4) | `1 ~ N` 중 **중복 허용**, M개를 골라 **비내림차순**(`a ≤ b ≤ …`) 수열 출력 |
| **15657** N과 M(8) | `1~N` 대신 입력값 사용 |

`1 2` 는 나오지만 `2 1` 은 안 나온다. **순서가 없다.**

## 2. 필요한 이론
→ [G04 경우의 수 — 하나의 골격, 두 개의 스위치](../../theory/G04_경우의수.md)

| 축 | 값 |
|---|---|
| 순서 | **X** |
| 중복 | **O** |

> **순서를 없애는 방법 = 오름차순으로만 뽑는다.**
> `1 2` 와 `2 1` 중 오름차순인 `1 2` 만 만들면 자동으로 중복 제거가 된다.
> 이를 구현하는 것이 **`start` 인자**다.

[28번 중복순열](28_BOJ_15651_15656_중복순열.md)에서 딱 두 군데가 바뀐다.
```
for (int i = 1; ...)          →  for (int i = start; ...)
DFS(depth + 1)                →  DFS(depth + 1, i)
```

## 3. 코드 흐름
```
main()
 └ scanf(N, M)
   DFS(0, 1)                 ← 시작은 depth=0, start=1

DFS(depth, start):
   if (depth == M) { printCases(); return; }
   for i in start..N:                    ★ 1이 아니라 start
      num_of_cases[depth] = i
      DFS(depth + 1, i)                  ★ i (i+1 아님)
```

## 4. 핵심 코드

### 15652
```c
// DFS로 중복 조합 생성
// depth : 현재 자리, start : 이번 자리에 놓을 수 있는 최솟값
void DFS(int depth, int start)
{
    if (depth == M)
    {
        printCases();
        return;
    }

    // 오름차순 유지를 위해 start부터 시작
    for (int i = start; i <= N; i++)
    {
        num_of_cases[depth] = i;

        // 중복 허용이므로 다음 자리에서도 i를 다시 고를 수 있다
        DFS(depth + 1, i);       // ★★ i + 1 이 아니라 i
    }
}
```

### ★★ `i` 냐 `i + 1` 이냐 — 이 그룹 전체의 갈림길

```c
DFS(depth + 1, i);       // 중복조합 — 이번 자리 값을 다음에도 쓸 수 있다
DFS(depth + 1, i + 1);   // 조합    — 이번 자리 값보다 큰 것만
```

**딱 1 차이로 문제가 완전히 바뀐다.**

| | 다음 재귀 | `2 2` 가능? | `N=4,M=2` 개수 |
|---|---|---|---|
| 중복조합 (이 문제) | `i` | ✓ | 10 |
| [조합](31_BOJ_15650_15655_15664_조합.md) | `i + 1` | ✗ | 6 |

[27번 §4](27_경우의수_순열_조합_중복순열_중복조합.md)의 3중 for에서 `b = a` vs `b = a + 1` 과 **같은 차이**다. 두 형태를 함께 새겨두면 평생 안 헷갈린다.

### 15657 — 입력값 사용 + 정렬
```c
for (int i = 1; i <= N; i++)
    scanf("%d", &number[i]);

// 사전순 출력을 위해 오름차순 정렬
for (int i = 1; i <= N - 1; i++)
    for (int k = i + 1; k <= N; k++)
        if (number[i] > number[k]) { /* swap */ }
```
DFS 안에서 `num_of_cases[depth] = number[i]` 로 바뀐다.
**여기서 정렬은 사전순 출력만이 아니라 "비내림차순 수열"의 전제**이기도 하다. 정렬 안 된 `number[]` 에 `start` 를 적용하면 값이 오름차순이 아니게 된다.

## 5. 예제 손 추적 — `N=4, M=2` (15652)

`DFS(0, 1)` 부터. `start` 가 어떻게 가지를 잘라내는지 보는 게 핵심이다.

```
depth 0, start=1
  i=1 → DFS(1, 1) : i=1,2,3,4  →  1 1 | 1 2 | 1 3 | 1 4
  i=2 → DFS(1, 2) : i=2,3,4    →  2 2 | 2 3 | 2 4       ★ i=1 이 잘림
  i=3 → DFS(1, 3) : i=3,4      →  3 3 | 3 4             ★ i=1,2 잘림
  i=4 → DFS(1, 4) : i=4        →  4 4                   ★ i=1,2,3 잘림
```

| 순번 | 출력 | 순번 | 출력 |
|---|---|---|---|
| 1 | `1 1` | 6 | `2 3` |
| 2 | `1 2` | 7 | `2 4` |
| 3 | `1 3` | 8 | `3 3` |
| 4 | `1 4` | 9 | `3 4` |
| 5 | `2 2` | 10 | `4 4` |

**총 10가지.** 공식으로도 확인: `4H2 = C(4+2-1, 2) = C(5,2) = 10` ✓

> 실행으로 검증했다.
> ```bash
> printf '4 2\n' | python3 docs/split.py 29_BOJ_15652_15657_중복조합.cpp 15652
> ```

### `2 1` 은 어디로 갔나
[28번 중복순열](28_BOJ_15651_15656_중복순열.md)의 16가지 중 `2 1`, `3 1`, `3 2`, `4 1`, `4 2`, `4 3` 여섯 개가 사라졌다.
전부 **내림차순 쌍**이다. `start` 가 `i=2` 이후 `1` 을 못 고르게 막았기 때문.
`16 - 6 = 10` ✓

### 만약 `DFS(depth+1, i+1)` 로 바꾸면
`1 1`, `2 2`, `3 3`, `4 4` 네 개가 추가로 사라져 **6가지**가 된다 → 그게 [조합](31_BOJ_15650_15655_15664_조합.md)이다.

## 6. 함정 / 예상 함정
- **★★ `DFS(depth+1, i+1)` 로 씀** → 조합이 되어 `1 1` 같은 게 빠진다. 반대로 조합 문제에 `i` 를 쓰면 답이 부푼다. **이 그룹 최다 실수.**
- **★ `for (int i = 1; ...)` 로 씀** → `start` 를 무시해 중복순열이 된다. `i = start` 여야 한다.
- **★ 최초 호출을 `DFS(0)` 으로.** 인자가 두 개다. `DFS(0, 1)` — `start` 초기값 1을 빠뜨리면 컴파일은 되지만(기본값이 없으면 오류) 쓰레기값이 들어간다.
- **15657에서 정렬 누락.** 사전순도 깨지고, 값이 비내림차순이 아니게 된다.
- **종료 조건 뒤 `return` 누락** — [28번](28_BOJ_15651_15656_중복순열.md)과 동일.
- **개수 공식 착각.** `nHr = C(n+r-1, r)` 이지 `n^r` 도 `nCr` 도 아니다.
- 한 파일에 두 프로그램 — 그대로 컴파일 불가.
