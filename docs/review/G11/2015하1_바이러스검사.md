## 1. 문제 요약
각 식당마다 검사해야 할 인원 수가 주어진다.

**배치 규칙**
1. 각 식당에는 **팀장 검사관 1명을 반드시** 배치한다
2. 팀장이 검사하고 **남은 인원이 있으면** 팀원 검사관을 추가 배치한다

**검사 가능 인원**
- 팀장 1명: `leader` 명
- 팀원 1명: `member` 명

모든 식당을 검사하는 데 필요한 **총 검사관 수**를 구한다.

## 2. 필요한 이론
→ [G11 그리디 · DP](../../theory/G11_그리디DP.md)

**격자도, 탐색도, 시뮬레이션도 없다.** 이 레포에서 가장 이질적인 문제다.

> ### ★★ 핵심: 식당끼리 서로 영향을 주지 않는다
> 한 식당에 배치한 검사관이 다른 식당에 영향을 주지 않는다.
> → **각 식당을 독립적으로 계산해서 더하면 끝.** 그리디가 성립하는 근거다.
>
> "여러 식당을 한 검사관이 담당할 수 있나?"를 지문에서 확인하는 것이 첫 단계다.
> **못 한다면 독립**이고, 이 문제는 그렇다.

핵심 도구는 하나: **올림 나눗셈**.

## 3. 코드 흐름
```
main()
 └ input()          N, restaurant[], leader, member
   각 식당에서 leader 명을 뺀다
   sum = N                      ★ 팀장은 무조건 식당당 1명
   남은 인원 > 0 인 식당마다:
      sum += 올림(남은 / member)
   printf(sum)
```

## 4. 핵심 코드

### 전체
```c
typedef long long ll;

ll sum = 0;

// 1) 모든 식당에서 팀장이 담당할 인원을 뺀다
for (int i = 0; i < N; i++)
    restaurant[i] -= leader;

// 2) 팀장은 식당마다 반드시 1명
sum += N;

// 3) 남은 인원은 팀원이 나눠 담당
for (int i = 0; i < N; i++)
{
    if (restaurant[i] > 0)
        sum += ((restaurant[i] - 1) / member) + 1;    // ★ 올림 나눗셈
}

printf("%lld\n", sum);
```

**세 줄이 전부다.** 하지만 각 줄에 함정이 하나씩 있다.

### ★★ 올림 나눗셈 관용구
```c
((x - 1) / d) + 1        // ★ x를 d로 나눈 올림 (x > 0 일 때)
```

**왜 `x / d + 1` 이 아닌가**
```
x = 10, d = 5:
  올바른 답: 10 / 5 = 2 (딱 나누어떨어짐)

  ((10 - 1) / 5) + 1 = (9 / 5) + 1 = 1 + 1 = 2 ✓
  (10 / 5) + 1       = 2 + 1 = 3               ✗ 하나 더 셈
```

```
x = 11, d = 5:
  올바른 답: 3 (5 + 5 + 1)

  ((11 - 1) / 5) + 1 = (10 / 5) + 1 = 2 + 1 = 3 ✓
```

**`x` 가 `d` 의 배수일 때 정확히 갈린다.** A형에서 반복 등장하는 관용구이니 통째로 외운다.

> **`x > 0` 전제**가 붙는다. `x == 0` 이면 `((0-1)/d)+1` 이 `0 + 1 = 1` 이 되어 틀린다
> (C에서 `-1 / 5 == 0`). 그래서 코드가 **`if (restaurant[i] > 0)`** 로 감싼다.

### ★ `long long` 이 필요한 이유
```c
#define MAX (1000000 + 50000)
typedef long long ll;

ll sum = 0;
```

**식당이 최대 100만 개**다. 각 식당에서 검사관이 여러 명 나올 수 있으므로
`sum` 이 `int` 범위(21억)를 넘길 수 있다.

**출력도 `%lld`** 여야 한다. `%d` 로 출력하면 값이 잘린다.

> 이 레포에서 **`long long` 을 쓰는 유일한 파일**이다.
> "N이 100만"이라는 입력 크기를 보고 **오버플로를 먼저 의심**하는 감각이 필요하다.

### 팀장을 먼저 빼는 이유
```c
for (int i = 0; i < N; i++)
    restaurant[i] -= leader;

sum += N;
```

규칙 1이 "**반드시** 팀장 1명"이므로, 인원이 적어도 팀장은 배치된다.
- 인원 3명, `leader = 5` → 팀장 1명으로 충분, 남은 인원 `-2` (음수)
- 음수는 `if (> 0)` 에서 걸러진다

**`restaurant[i]` 를 직접 수정**해도 되는 이유: 이후에 원본이 필요 없기 때문.

## 5. 예제 손 추적

### 기본
```
식당 3개: [10, 3, 20]
leader = 5, member = 3

① 팀장 몫 빼기: [5, -2, 15]
② sum = 3 (팀장 3명)

③ 팀원:
   식당0: 5 > 0  →  ((5-1)/3)+1 = (4/3)+1 = 1+1 = 2
   식당1: -2 ≤ 0 →  건너뜀           ★ 팀장만으로 충분
   식당2: 15 > 0 →  ((15-1)/3)+1 = (14/3)+1 = 4+1 = 5

sum = 3 + 2 + 0 + 5 = 10
```

**검산**
```
식당0: 10명 = 팀장 5 + 팀원 5 → 팀원 2명(3+3=6 ≥ 5) ✓  총 3명
식당1:  3명 = 팀장 5 로 충분              ✓  총 1명
식당2: 20명 = 팀장 5 + 팀원 15 → 팀원 5명(15) ✓  총 6명
합계 = 3 + 1 + 6 = 10 ✓
```

### 딱 나누어떨어지는 경우
```
남은 인원 = 6, member = 3

((6-1)/3)+1 = (5/3)+1 = 1+1 = 2 ✓   (3+3 = 6)
(6/3)+1     = 2+1 = 3           ✗   하나 더 셈
```

### 팀장만으로 충분한 경우
```
인원 = 4, leader = 10
남은 = 4 - 10 = -6  →  if (-6 > 0) 거짓  →  팀원 0명

총 1명 (팀장) ✓
```

### `x == 0` 경계
```
인원 = 5, leader = 5
남은 = 0  →  if (0 > 0) 거짓  →  팀원 0명 ✓

만약 if 없이 계산했다면:
((0-1)/3)+1 = (-1/3)+1 = 0+1 = 1    ✗ 있지도 않은 팀원 1명
```
**`if (> 0)` 가드가 이 경계를 막는다.**

### 오버플로
```
식당 100만 개, 각각 팀원 1000명 필요
sum ≈ 100만 × 1001 = 10억 1백만

int 범위(약 21억) 안이지만, 조건이 더 크면 넘친다
→ long long 이 안전
```

## 6. 함정 / 예상 함정
- **★★ 올림 나눗셈을 `x / d + 1` 로.** 딱 나누어떨어질 때 하나 더 센다. **`((x-1)/d)+1`**.
- **★★ `x == 0` 가드 누락.** `((0-1)/d)+1 = 1` 이 되어 없는 검사관을 센다. **`if (x > 0)`** 필수.
- **★★ `int` 오버플로.** N이 100만이다. `long long` + `%lld`.
- **★ 팀장을 조건부로 배치.** 인원이 적어도 **반드시 1명**이다. `sum += N` 이 무조건 실행돼야 한다.
- **★ 그리디 성립 근거를 확인 안 함.** "한 검사관이 여러 식당을 담당할 수 있는가"를 지문에서 확인. 가능하다면 완전히 다른 문제가 된다.
- **`%d` 로 출력.** `long long` 은 `%lld`.
- **`restaurant[]` 배열 크기.** N이 100만이므로 `MAX` 를 그만큼 잡아야 한다.
- **음수 인원을 그대로 나눔.** C의 음수 나눗셈은 0쪽으로 버림이라 예상과 다르게 동작한다.

## 7. 백지 재현 체크리스트
- [ ] **식당끼리 독립**임을 확인하고 그리디를 적용하는가
- [ ] **올림 나눗셈 `((x-1)/d)+1`** 을 정확히 쓰는가
- [ ] **`x > 0` 가드**를 넣었는가
- [ ] 팀장을 **무조건 N명** 세는가
- [ ] 입력 크기를 보고 **`long long`** 을 판단했는가
- [ ] 출력 형식이 **`%lld`** 인가
- [ ] `x` 가 `d` 의 배수일 때를 손으로 검산했는가

## 8. 한 줄 요약
"**식당이 독립이라 그리디.** 올림 나눗셈은 **`((x-1)/d)+1`**, 단 **`x > 0`** 일 때만. N이 크면 **`long long`**."
