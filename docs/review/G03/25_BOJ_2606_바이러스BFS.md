## 1. 문제 요약
[24번](24_BOJ_2606_바이러스DFS.md)과 동일하다. 1번 컴퓨터를 통해 감염되는 컴퓨터 수를 센다.

**이 노트의 목적은 문제가 아니라 DFS ↔ BFS 대응을 몸에 익히는 것이다.**

## 2. 필요한 이론
→ [G03 DFS/BFS 기초 — BFS](../../theory/G03_DFS_BFS기초.md)

도달 가능성만 묻는 문제라 DFS도 BFS도 답이 같다. 하지만 **방문 순서가 다르고**, 실전에서는 이 차이가 갈림길이 된다.

| | DFS ([24번](24_BOJ_2606_바이러스DFS.md)) | BFS (이 문제) |
|---|---|---|
| 자료구조 | 재귀 호출 스택 | 배열 큐 `rp/wp` |
| `visit` 찍는 시점 | 함수 진입 직후 | **큐에 넣는 순간** ★ |
| `count++` 위치 | 재귀 호출 직전 | 큐에 넣기 직전 |
| 이 예제 방문 순서 | `1 2 3 5 6` | `1 2 5 3 6` |
| 최단 거리 | ✗ | ✓ (여기선 안 쓰지만) |

> **최단 거리가 필요해지는 순간 BFS 말고 선택지가 없다.** 그래서 기출에서는 BFS 비중이 압도적이다. DFS는 [G04 백트래킹](../../theory/G04_경우의수.md)에서 다른 역할로 살아남는다.

## 3. 코드 흐름
```
main()
 └ input()          V, E, 간선 → 인접 행렬 (양방향)
   BFS(1)           큐 탐색, 넣을 때마다 count++, 마지막에 출력
```

`count` 가 [24번](24_BOJ_2606_바이러스DFS.md)과 달리 **함수 지역 변수**다. 재귀가 아니라 한 함수 안에서 끝나므로 전역일 필요가 없다 — BFS의 부수적 장점.

## 4. 핵심 코드

### BFS 전체
```c
void BFS(int node)
{
    int rp, wp;   // rp: read pointer (꺼낼 위치), wp: write pointer (넣을 위치)
    int count;    // 감염된 컴퓨터 수 (1번 제외)

    rp = wp = 0;  // 큐 초기화

    // 시작 노드를 큐에 삽입
    queue[wp++] = node;
    visit[node] = true;      // ★ 시작 노드 방문 처리

    count = 0;

    // 큐가 빌 때까지 반복
    while (rp < wp)
    {
        int out = queue[rp++];   // 큐에서 하나 꺼냄

        for (int c = 1; c <= V; c++)
        {
            // 연결 안 되어 있거나 이미 방문한 경우 skip
            if (MAP[out][c] == 0 || visit[c] == true)
                continue;

            count++;             // 새롭게 감염된 컴퓨터

            queue[wp++] = c;     // 큐에 추가
            visit[c] = true;     // ★★ 넣는 순간 방문 처리
        }
    }

    printf("%d\n", count);
}
```

### ★★ `visit` 을 넣을 때 찍는다 — 이 그룹 최대 포인트
```c
queue[wp++] = c;
visit[c] = true;      // ← 여기. 꺼낼 때가 아니다.
```

**꺼낼 때 찍으면 왜 틀리는가** — 이 예제로 바로 확인된다.

정점 `2` 와 `5` 가 둘 다 `1` 에 연결되어 있고, 서로도 연결되어 있다(`5 2` 간선).
- 넣을 때 찍는 방식: `1` 처리 시 `2`, `5` 가 큐에 들어가며 즉시 표시됨. `2` 를 꺼내 스캔할 때 `5` 는 이미 방문 → skip. **정상**
- 꺼낼 때 찍는 방식: `1` 처리 시 `2`, `5` 가 큐에 들어가지만 **표시는 안 됨**. `2` 를 꺼내 스캔하면 `5` 가 미방문으로 보여 **또 큐에 들어간다.** `count` 가 부풀고 큐도 부푼다

> 이 규칙은 격자 BFS와 기출 전체에 그대로 적용된다. **BFS를 쓸 때마다 이 줄을 확인하는 습관**을 들인다.

### 큐 배열 크기
```c
int queue[MAX * MAX];
```
`rp/wp` 가 전진만 하므로 총 삽입 횟수 기준이다 ([G02 §큐](../../theory/G02_스택큐덱.md)).
`visit` 을 넣을 때 찍으면 각 정점은 **최대 한 번만** 들어가므로 사실 `MAX` 면 충분하다.
`MAX * MAX` 는 "꺼낼 때 찍는 실수"까지 흡수하는 넉넉한 크기 — 습관적으로 크게 잡는 편이 안전하다.

## 5. 예제 손 추적 — BOJ 2606 예제 (24번과 같은 입력)

```
      1 ── 2 ── 3
      │   ╱
      │  ╱
      5 ─┘
      │
      6              4 ── 7
```

| 단계 | 꺼낸 값 `out` | 스캔 결과 | 큐 상태 (`rp` 이후) | `count` |
|---|---|---|---|---|
| 초기 | — | `1` 삽입, `visit[1]=T` | `[1]` | 0 |
| 1 | **1** | c=2 신규 → 삽입<br>c=5 신규 → 삽입 | `[2, 5]` | **2** |
| 2 | **2** | c=1 방문됨<br>c=3 신규 → 삽입<br>c=5 **이미 방문** ★ | `[5, 3]` | **3** |
| 3 | **5** | c=1,2 방문됨<br>c=6 신규 → 삽입 | `[3, 6]` | **4** |
| 4 | **3** | c=2 방문됨 | `[6]` | 4 |
| 5 | **6** | c=5 방문됨 | `[]` | 4 |
| 종료 | `rp == wp` | | | **4** |

```
출력    4
```

> 실행으로 검증했다.
> ```bash
> printf '7\n6\n1 2\n2 3\n1 5\n5 2\n5 6\n4 7\n' | ./a.out    # 4
> ```

**단계 2의 `c=5 이미 방문`** 이 핵심 장면이다. `5` 는 단계 1에서 큐에 **넣을 때** 표시됐기 때문에 여기서 걸러진다. 꺼낼 때 찍는 방식이었다면 `5` 가 큐에 두 번 들어가고 `count` 가 5가 됐을 것이다.

**방문 순서 비교**
```
DFS:  1 → 2 → 3 → 5 → 6      (2에서 3까지 끝까지 내려갔다 복귀)
BFS:  1 → 2 → 5 → 3 → 6      (1의 이웃 2,5를 먼저 다 보고 다음 층)
```
BFS는 시작점에서 가까운 순서다. 그래서 **처음 도달했을 때가 곧 최단**이 된다.

## 6. 함정 / 예상 함정
- **★★ `visit` 을 dequeue 시점에 찍음.** 위 §4·§5 참조. 중복 삽입 → `count` 부풀림 → 큐 오버플로. **BFS 최다 실수.**
- **★ 시작 노드 방문 처리 누락.** `visit[node] = true` 를 빼면 `1` 의 이웃을 스캔할 때 `1` 로 되돌아오는 간선을 타고 다시 들어간다.
- **`while (rp < wp)` 를 `while (rp != wp)` 로.** 여기선 같지만, `rp` 가 `wp` 를 추월할 수 있는 구현(원형 큐 등)에서는 무한 루프가 된다. `<` 가 안전.
- **간선 양방향 등록 누락** ([24번](24_BOJ_2606_바이러스DFS.md)과 동일).
- **`count` 를 큐 삽입 수가 아니라 dequeue 수로 셈.** 결과는 같지만(1번이 한 번 더 꺼내지므로 `-1` 필요) 헷갈린다. **삽입할 때 세는 쪽**이 "1번 제외"와 자연스럽게 맞는다.
- **큐 크기 부족** — [G02 20번 카드1](../G02/20_BOJ_2161_카드1.md)의 교훈.

## 7. 백지 재현 체크리스트
- [ ] `rp = wp = 0` → 시작 노드 삽입 → **시작 노드 방문 처리** 순서를 지켰는가
- [ ] `while (rp < wp)` 로 큐 소진을 판정하는가
- [ ] **`visit` 을 큐에 넣는 순간** 찍는가, 왜 그래야 하는지 설명할 수 있는가
- [ ] `연결 없음 || 이미 방문 → continue` 관용구를 쓸 수 있는가
- [ ] `count++` 를 삽입 직전에 두어 "1번 제외"를 만족시켰는가
- [ ] 같은 문제의 DFS 버전과 **방문 순서 차이**를 설명할 수 있는가
- [ ] 이 골격을 `RC` 구조체 격자 버전으로 바꿔 쓸 수 있는가

## 8. 한 줄 요약
"BFS는 **큐에 넣는 순간 `visit`을 찍는다.** 이거 하나면 나머지는 DFS와 같다."
