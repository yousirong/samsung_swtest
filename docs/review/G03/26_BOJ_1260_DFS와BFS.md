| 항목 | 내용 |
|---|---|
| 유형 | G03 DFS/BFS 기초 ★ **두 탐색을 한 파일에서** |

## 1. 문제 요약
정점 N개, 간선 M개인 무방향 그래프와 시작 정점 V가 주어진다.
**DFS 방문 순서**와 **BFS 방문 순서**를 각각 한 줄씩 출력한다.

> **조건: 갈 수 있는 정점이 여러 개면 항상 번호가 작은 것부터 방문한다.**

## 2. 필요한 이론
→ [G03 DFS/BFS 기초](../../theory/G03_DFS_BFS기초.md)

[24](24_BOJ_2606_바이러스DFS.md)·[25](25_BOJ_2606_바이러스BFS.md)에서 만든 두 함수를 그대로 합친 문제다. 새로 챙길 것은 두 가지:

1. **"번호가 작은 것부터" 조건** — 인접 행렬을 쓰면 공짜로 해결된다
2. **`visit` 초기화** — DFS 다음에 BFS를 돌리려면 사이에 리셋이 필요하다

## 3. 코드 흐름
```
main()
 └ input()                      N, M, V, 간선 → 인접 행렬 (양방향)
   DFS(V);  putchar('\n')
   for i in 1..N: visit[i] = false      ★ 초기화
   BFS(V);  putchar('\n')
```

## 4. 핵심 코드

### "번호가 작은 것부터"를 인접 행렬이 해결한다
```c
int MAP[MAX][MAX];    // 인접 행렬 (연결 여부 저장)

// 탐색 루프
for (int c = 1; c <= N; c++)
{
    if (MAP[node][c] == 0 || visit[c] == true) continue;
    ...
}
```

**`c` 를 1부터 올려가며 도는 것 자체가 오름차순 방문**이다.
인접 리스트였다면 입력 순서대로 쌓여서 별도 정렬이 필요했을 것 — 이게 A형에서 인접 행렬을 선호하는 이유다. (N이 작아 `O(N²)` 이 부담되지 않는다.)

### DFS — 방문 순서 출력이 추가됨
```c
void DFS(int node)
{
    visit[node] = true;          // 현재 노드 방문 처리
    printf("%d ", node);         // ★ 방문 순서 출력

    // 1번부터 N번까지 순서대로 확인 (작은 번호 우선)
    for (int c = 1; c <= N; c++)
    {
        if (MAP[node][c] == 0 || visit[c] == true) continue;
        DFS(c);                  // 연결된 노드로 재귀 호출
    }
}
```
출력이 `visit` 바로 다음에 온다. **방문 처리와 출력이 같은 시점**이라 순서가 어긋날 여지가 없다.

### BFS — 출력은 꺼낼 때
```c
void BFS(int node)
{
    int rp, wp;
    rp = wp = 0;

    queue[wp++] = node;
    visit[node] = true;

    while (rp < wp)
    {
        int out = queue[rp++];
        printf("%d ", out);          // ★ 출력은 꺼낼 때

        for (int c = 1; c <= N; c++)
        {
            if (MAP[out][c] == 0 || visit[c] == true) continue;

            queue[wp++] = c;
            visit[c] = true;         // ★★ 방문 처리는 넣을 때
        }
    }
}
```

> **★ BFS에서 출력 시점과 방문 처리 시점이 다르다.**
> - `visit` 은 **넣을 때** (중복 방지)
> - `printf` 는 **꺼낼 때** (방문 순서)
>
> 넣을 때 출력하면 순서가 틀린다. 위 예제로 확인: 넣을 때 출력하면 `1`이 맨 앞에 안 나온다(시작 노드는 스캔 없이 삽입되므로).
> **이 두 시점의 분리가 이 문제의 핵심**이다.

### `visit` 초기화
```c
DFS(V);
putchar('\n');

// BFS 전에 visit 배열 초기화
// DFS에서 이미 사용했기 때문에 다시 false로 초기화 필요
for (int i = 1; i <= N; i++)
    visit[i] = false;

BFS(V);
```
빼먹으면 **BFS가 시작 정점만 출력하고 끝난다.** 모든 정점이 이미 방문 표시이기 때문.

## 5. 예제 손 추적

### (가) BOJ 1260 예제 — `N=4, M=5, V=1`
```
간선: 1-2, 1-3, 1-4, 2-4, 3-4

      1
    ╱ │ ╲
   2  3  4
    ╲ │ ╱
     (2-4, 3-4)
```

**DFS(1)**
| 깊이 | 호출 | 스캔 | 출력 |
|---|---|---|---|
| 0 | `DFS(1)` | | `1` |
| 0 | | c=2 신규 → 내려감 | |
| 1 | `DFS(2)` | | `2` |
| 1 | | c=1 방문됨, c=4 신규 → 내려감 | |
| 2 | `DFS(4)` | | `4` |
| 2 | | c=1,2 방문됨, c=3 신규 → 내려감 | |
| 3 | `DFS(3)` | c=1,4 방문됨 → 복귀 | `3` |
| — | 나머지 전부 방문됨 → 종료 | | |

→ `1 2 4 3`

**BFS(1)**
| 단계 | 꺼낸 값 | 스캔 → 삽입 | 큐 | 출력 |
|---|---|---|---|---|
| 초기 | — | `1` 삽입 | `[1]` | |
| 1 | **1** | c=2,3,4 전부 신규 → 삽입 | `[2,3,4]` | `1` |
| 2 | **2** | c=1,4 이미 방문 | `[3,4]` | `2` |
| 3 | **3** | c=1,4 이미 방문 | `[4]` | `3` |
| 4 | **4** | c=1,2,3 이미 방문 | `[]` | `4` |

→ `1 2 3 4`

```
출력    1 2 4 3
        1 2 3 4
```

**차이의 정체**: DFS는 `2` 로 내려간 뒤 **거기서 갈 수 있는 곳(`4`)을 먼저** 판다. BFS는 `1` 의 이웃 `2,3,4` 를 **한 층 통째로** 먼저 담는다.

### (나) 시작 정점이 1이 아닌 경우 — `N=5, M=5, V=3`
```
간선: 5-4, 5-2, 1-2, 3-4, 3-1
```
```
출력    3 1 2 5 4
        3 1 4 2 5
```
- **DFS**: `3` → (c=1 이 c=4 보다 작으므로) `1` → `2` → `5` → `4`
- **BFS**: `3` 의 이웃 `1, 4` 를 먼저 담고 → `1` 의 이웃 `2` → `4` 의 이웃 `5`

> 두 예제 모두 실행으로 검증했다.
> ```bash
> printf '4 5 1\n1 2\n1 3\n1 4\n2 4\n3 4\n' | ./a.out
> printf '5 5 3\n5 4\n5 2\n1 2\n3 4\n3 1\n' | ./a.out
> ```
> (나)의 DFS 첫 갈림길(`3` 에서 `1` 이냐 `4` 냐)이 **"번호가 작은 것부터" 조건의 실제 작동 지점**이다.

## 6. 함정 / 예상 함정
- **★★ `visit` 초기화 누락.** DFS 후 리셋하지 않으면 BFS가 시작 정점 하나만 출력한다. 이 문제에서 가장 흔한 실패.
- **★★ BFS에서 출력 시점.** `visit` 은 넣을 때, `printf` 는 **꺼낼 때**. 넣을 때 출력하면 시작 정점이 빠지고 순서도 틀린다.
- **★ "번호가 작은 것부터" 위반.** 인접 리스트를 입력 순서대로 쓰면 조건을 어긴다. 인접 행렬을 쓰거나, 리스트라면 정렬해야 한다.
- **간선 양방향 등록 누락** — 세 문제 공통.
- **중복 간선 / 자기 루프.** 문제에 따라 같은 간선이 두 번 들어올 수 있다. 인접 행렬은 `= 1` 대입이라 자동으로 흡수한다 (리스트는 중복이 쌓임) — 행렬의 또 다른 장점.
- **출력 형식.** 각 줄 끝 개행. 마지막 정점 뒤 공백은 대개 허용된다.
- **시작 정점 `V` 를 1로 하드코딩.** 입력으로 받는다. (나) 예제가 이걸 잡는다.

## 7. 백지 재현 체크리스트
- [ ] 인접 행렬 + `c = 1..N` 루프가 **"번호 작은 순"을 자동 보장**함을 아는가
- [ ] DFS에서 `visit` 과 `printf` 가 **같은 시점**인가
- [ ] BFS에서 `visit` 은 **넣을 때**, `printf` 는 **꺼낼 때** — 분리했는가
- [ ] DFS와 BFS 사이에 `visit` 을 초기화했는가
- [ ] 시작 정점을 입력으로 받는가
- [ ] 같은 그래프에서 두 방문 순서가 왜 달라지는지 설명할 수 있는가

## 8. 한 줄 요약
"인접 행렬이 **번호 순서**를 보장하고, BFS는 **넣을 때 `visit` / 꺼낼 때 `printf`**, 사이에 **초기화**."
