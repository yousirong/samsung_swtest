## ⚠️ 현재 상태

파일 전체가 이것뿐이다.
```c
#include <stdio.h>

#define MAX_N (50 + 5)
#define MAX_M (100+10)

int T;

int N, M;
```

**`main()` 이 없어 컴파일도 안 된다.** 손도 못 댄 상태다.

> `MAX_N (50 + 5)`, `MAX_M (100 + 10)` 이라는 상수만 봐도
> **격자가 `50×50` 이하이고 명령이 100개 이하**라는 것은 파악하고 시작했음을 알 수 있다.

**[격자 숫자 놀이](../G10/2019상오후1_격자숫자놀이.md)와 함께 이 레포의 유이한 미해결 문제**다.

## 이 노트의 목적

다른 노트는 "코드를 읽고 정리"하지만, **이 노트는 반대다.**
**설계를 먼저 적고 그것을 보며 구현**한다 — 그게 실전 A형의 순서이기도 하다.

### 진행 방식 (다른 그룹과 순서가 반대)
```
① 문제 지문을 읽고 §1(요약)·§2(필요한 이론) 채우기
② §3(설계)를 코드 없이 글로 작성
③ 어떤 이론 카드가 걸리는지 링크
④ 그 설계대로 구현
⑤ 구현하며 부딪힌 것을 §6(함정)에 기록
⑥ §7(백지 재현 체크리스트)로 닫기
```

## 1. 문제 요약

> 🔴 **직접 채울 것.** 문제 지문을 읽고 아래 형식으로 정리한다.

```
격자 크기      :
초기 상태      :
매 턴 규칙     : 1.
                2.
                3.
종료 조건      :
출력           :
```

**참고**: 코드트리 "나무 타이쿤"은 삼성 기출 중 **격자 회전 + 성장 시뮬레이션** 계열로 알려져 있다.
`MAX_M = 100 + 10` 이라는 상수가 **"명령 M개를 순서대로 처리"** 구조를 암시한다.

## 3. 설계 — 코드 쓰기 전에 글로

> 🔴 **직접 채울 것.**

```
main()
 └ input()
   for m in 0..M-1:          명령 M개
      step1()
      step2()
      ...
   printf(getAnswer())
```

### 자료구조 결정
| 항목 | 선택 | 이유 |
|---|---|---|
| 격자 | `int MAP[MAX_N][MAX_N]` | |
| 임시 배열 필요? | | "동시에" 규칙이 있으면 필수 |
| 방향 배열 | | 문제가 요구하는 순서로 |
| 상수 | `MAX_N = 55`, `MAX_M = 110` | 스텁에 이미 있음 |

## 4. 구현 전 체크리스트 — 이 레포에서 반복된 함정

지금까지 66문제를 복습하며 나온 **최빈 실수**들이다. 구현하며 하나씩 확인한다.

### 동시성
- [ ] **"동시에" 일어나는 변화를 `tmpMAP` 으로 분리**했는가
  → [회전하는 빙하](../G06/2020하오후2_회전하는빙하.md), [시공의 돌풍](../G10/2019상오전1_시공의돌풍.md), [랩 인턴](../G10/2019상오전2_생명과학부랩인턴.md)
- [ ] **판정과 반영을 분리**했는가 → [팔각의자](../G06/2017하오후1_돌아가는팔각의자.md)

### 회전 / 배열
- [ ] 회전 전 **`copyMap(temp, MAP)`** 했는가 → [G01 제1원칙](../../theory/G01_배열회전.md)
- [ ] 90도 회전에서 **`N ↔ M` swap 을 먼저** 했는가 → [14번](../G01/14_BOJ_16935_배열돌리기3.md)
- [ ] 밀어내기를 **흐름 반대 방향부터** 했는가 → [무빙워크](../G10/2020하오전1_불안한무빙워크.md)

### 방향
- [ ] 방향 배열 순서가 **문제의 우선순위와 일치**하는가 → [G05](../../theory/G05_그리드탐색심화.md)
- [ ] 1-based 라면 `[0]` 을 더미로 뒀는가 → [이상한 윷놀이](../G10/2019하오전2_이상한윷놀이.md)
- [ ] 원형 인덱스에 **`+ N` 보정**을 넣었는가 → [원자 충돌](../G10/2020하오전2_원자충돌.md)

### 우선순위
- [ ] 항목마다 **방향(크게/작게)** 을 정확히 썼는가
- [ ] **초기값을 각 항목 반대 방향**으로 잡았는가
  → [색깔 폭탄](../G09/2021상오전2_색깔폭탄.md), [놀이기구 탑승](../G10/2021상오전1_놀이기구탑승.md)
- [ ] 스캔 순서로 해결되면 **`<` 하나로** 끝내는가 → [전투로봇](../G09/2018하오후2_전투로봇.md)

### 자료구조
- [ ] 큐 배열 크기를 **총 push 횟수**로 잡았는가 → [G02 20번 카드1](../G02/20_BOJ_2161_카드1.md)
- [ ] 양쪽 삽입이 필요하면 **덱 + `OFFSET`** 을 썼는가 → [바이러스 실험](../G10/2018하오후1_바이러스실험.md)
- [ ] BFS에서 `visit` 을 **넣을 때** 찍는가 → [G03](../../theory/G03_DFS_BFS기초.md)

### 경계 / 초기화
- [ ] 테두리 **sentinel** 을 썼는가, 기본값 `0` 이 의미 있는 값은 아닌가
  → [토마토](../G05/38_BOJ_7576_토마토.md)의 함정
- [ ] **T-loop 마다 전역 초기화**를 했는가 → [섬의 개수](../G05/35_BOJ_4963_섬의개수.md)
- [ ] 지역 배열 `{0}` 으로 자동 초기화를 활용했는가

### 수치
- [ ] 정수 나눗셈(버림)이 의도한 대로인가
- [ ] 올림이 필요하면 **`((x-1)/d)+1`**, `x > 0` 가드까지 → [바이러스 검사](../G11/2015하1_바이러스검사.md)
- [ ] 입력 크기를 보고 **`long long`** 을 판단했는가

### 표로 펼치기
- [ ] 복잡한 분기를 **미리 표(배열)로 적어둘** 수 있는가
  → [테트리스 19모양](../G07/2017상오전1_테트리스블럭안의합최대화하기.md), [청소는 즐거워 비율표](../G10/2020하오후1_청소는즐거워.md),
  [윷놀이 사기단 전이표](../G07/2019하오후2_윷놀이사기단.md), [성곽 WALL표](../G05/40_BOJ_2234_성곽.md)
