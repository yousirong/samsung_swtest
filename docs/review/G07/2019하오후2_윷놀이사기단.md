## 1. 문제 요약
말 4개가 있고, **10번의 이동 횟수**가 주어진다. 매 턴 4개 중 **하나를 골라** 이동시킨다.

보드는 **일반 경로**와 **파란색 지름길 경로**가 있고, 특정 칸(`10`, `20`, `30`)에 처음 도착하면 지름길로 진입한다.

**규칙**
1. 매 턴 4개 말 중 하나를 선택해 이동
2. 이미 도착한 말은 계속 도착 위치에 머문다
3. **도착 칸을 제외하고, 같은 칸에 두 말이 동시에 있을 수 없다**
4. 10번의 이동을 모두 수행했을 때 **얻을 수 있는 점수 합의 최댓값**

## 2. 필요한 이론
→ [G07 표준 골격](../../theory/G07_완전탐색시뮬.md)

골격은 [2048](2016하2_2048게임.md)과 동일하다.
```
후보 = 매 턴 말 4개 중 하나 → 4^10 = 1,048,576 가지 (중복순열)
각 후보마다 10턴 시뮬레이션 → 100만 × 10 = 1000만 연산. 통과.
```

> **★ 이 문제의 진짜 난점은 탐색이 아니라 "보드를 어떻게 표현하는가"** 다.
> 지름길이 있는 비선형 보드를 좌표로 다루려 들면 지옥이 된다.
>
> **해법: 보드를 그래프로 미리 펼쳐서 `next[위치][칸수]` 전이표를 만든다.**
> 그러면 시뮬레이션이 **표 조회 한 줄**로 끝난다.

## 3. 코드 흐름
```
main()
 └ T-loop:
      input()                  move[0..9], next[][] 전이표, score[] 구성
      maxAnswer = 0
      DFS(0)
      printf(maxAnswer)

DFS(depth):
   if (depth == 10):
      tmp = simulate()
      maxAnswer = max(maxAnswer, tmp)
      return
   for i in 1..4:              말 1~4 중 하나
      num_of_cases[depth] = i
      DFS(depth + 1)

simulate():
   horsePos[1..4] = 0, board[] = false
   for i in 0..9:
      말 선택 → next[현재][이동칸] → 충돌 검사 → 갱신 → 점수 누적
   return sum
```

## 4. 핵심 코드

### ★★ 보드를 전이표로 — 이 문제의 전부
```c
#define MAX_BOARD (32 + 10)
#define DESTINATION (32)

int next[MAX_BOARD][6];   // next[현재 위치][이동 칸 수] = 다음 위치
int score[MAX_BOARD];     // score[위치] = 그 칸의 점수
```

**보드의 모든 칸에 번호를 매기고, "여기서 k칸 가면 어디"를 표로 만든다.**

- 일반 경로와 지름길을 **별개 번호**로 매긴다
- 지름길 진입점(`10`, `20`, `30`)에서는 `next` 가 지름길 쪽을 가리킨다
- 도착점은 `32` 번 하나로 통일

> **이 전이표를 만드는 것이 문제 풀이의 90%다.** 손으로 보드를 그리고 번호를 매긴 뒤 `next` 를 채운다.
> 표만 정확하면 시뮬레이션은 **10줄**이다.

**왜 표가 필요한가**: 지름길 때문에 "현재 위치 + 이동 칸수"가 **단순 덧셈이 아니다.**
```
일반 경로에서 10번 칸 → 지름길로 진입
지름길 안에서는 또 다른 경로
지름길이 끝나면 다시 일반 경로 합류
```
이걸 `if` 로 처리하려면 조건이 폭발한다. **표로 미리 펼치면 분기가 0개.**

### DFS — 순수 중복순열
```c
void DFS(int depth)
{
    // 10턴 선택을 모두 완료한 경우
    if (depth == 10)
    {
        int tmp = simulate();

        if (maxAnswer < tmp) maxAnswer = tmp;
        return;
    }

    // 현재 턴에서 1~4번 말 중 하나 선택
    for (int i = 1; i <= 4; i++)
    {
        num_of_cases[depth] = i;
        DFS(depth + 1);
    }
}
```
`visit` 도 `start` 도 없다. **같은 말을 연속으로 골라도 되고, 순서도 의미가 있다.**

### ★ 시뮬레이션 — 표 조회 + 충돌 검사
```c
int simulate()
{
    // 말 번호는 1~4를 사용하므로 0번 인덱스는 비워둠
    int horsePos[5] = { 0 };

    // 각 위치에 말이 존재하는지 체크
    bool board[MAX_BOARD] = { 0 };

    int sum = 0;

    for (int i = 0; i < 10; i++)
    {
        int horseNumber = num_of_cases[i];      // 이번 턴에 선택한 말
        int moveCount   = move[i];              // 이번 턴의 이동 칸 수

        int currentPos = horsePos[horseNumber];
        int nextPos    = next[currentPos][moveCount];    // ★ 표 조회 한 줄

        // 도착점이 아닌데 이미 다른 말이 있으면 불가능한 경우
        if (nextPos != DESTINATION && board[nextPos] == true)
            return 0;                            // ★ 실패 → 0점

        horsePos[horseNumber] = nextPos;
        board[currentPos] = false;               // 이전 칸 비우기
        board[nextPos]    = true;                // 새 칸 점유
        sum += score[nextPos];
    }

    return sum;
}
```

**네 가지 포인트**

**① 상태는 배열 두 개뿐.**
`horsePos[1..4]` (각 말의 위치) + `board[]` (칸 점유 여부).
보드 자체는 `next`/`score` 표로 고정이라 **복사할 필요가 없다** — [2개의 사탕](2015하2_2개의사탕.md)과 같은 상태 압축.

**② 충돌 시 `return 0`.**
실패를 "0점"으로 처리한다. 최댓값을 찾는 문제라 **0점 후보는 자동으로 탈락**한다.
`-1` 이나 `INF` 를 쓸 필요가 없다.

> ⚠️ 단, **모든 후보가 실패하면 답이 0**이 된다. 이 문제는 항상 유효한 선택이 존재하므로 안전하다.

**③ 도착점(`32`)은 충돌 예외.**
`nextPos != DESTINATION` 조건이 규칙 2("이미 도착한 말은 계속 머문다")를 구현한다. 도착점에는 말이 여러 개 겹칠 수 있다.

**④ `board[currentPos] = false` 를 먼저.**
자기 자신이 있던 칸을 비운 뒤 새 칸을 점유한다. 순서가 바뀌면 **제자리 이동 시 자기가 자기를 막는다** (이 문제에서는 `moveCount ≥ 1` 이라 발생하지 않지만, 습관으로 중요).

**⑤ 지역 배열로 매 호출 초기화.**
`horsePos`, `board` 를 `{ 0 }` 으로 선언해 **후보마다 자동 리셋**된다. 전역으로 빼면 명시적 초기화가 필요하다 — [G07 이론](../../theory/G07_완전탐색시뮬.md)의 "원본 보존"이 여기서는 이 형태로 나타난다.

## 5. 예제 손 추적 — 전이표의 동작

### 보드 번호 예시 (개념도)
```
일반 경로:  0 → 1 → 2 → ... → 10 → ... → 20 → ... → 30 → 31 → 32(도착)
                                ↓            ↓          ↓
지름길:                       [21..]      [24..]    [27..]
                                 └──────────┴──────────┘
                                       합류 → 31 → 32
```

`10`, `20`, `30` 에 **도착하면** 지름길로 빠진다. 그래서 `next[10][k]` 는 일반 경로가 아니라 지름길 번호를 가리킨다.

### 시뮬레이션 한 턴
```
현재: horsePos[2] = 10        (2번 말이 10번 칸에)
이번 턴: move[i] = 3, 2번 말 선택

nextPos = next[10][3]         ★ 표가 지름길 경로를 알려준다
        = (지름길 3칸 이동한 위치)
```
**`10 + 3 = 13` 이 아니다.** 표가 없으면 이 분기를 매번 `if` 로 처리해야 한다.

### 충돌 발생
```
horsePos = [_, 5, 12, 5, 0]      1번과 3번 말이 둘 다 5번 칸? → 불가능한 상태

실제로는:
  1번 말이 5번 칸에 있고 board[5] = true
  3번 말을 움직였더니 nextPos = 5
  → nextPos != 32 이고 board[5] == true
  → return 0                     ★ 이 후보 전체가 무효
```

### 도착점 예외
```
1번 말이 이미 DESTINATION(32)에 있고 board[32] = true
2번 말도 32로 이동
  → nextPos == 32 이므로 충돌 검사를 건너뛴다
  → 정상 진행 ✓
```

### 점수 누적
```
sum += score[nextPos]
```
**도착한 칸의 점수만** 더한다. 지나가는 칸은 안 센다 — 지문 확인 필수.

## 6. 함정 / 예상 함정
- **★★ 전이표를 안 만들고 좌표/조건문으로 처리.** 지름길 분기가 폭발한다. **`next[위치][칸수]` 표가 정답.**
- **★★ 전이표를 잘못 채움.** 이 문제의 실질적 난이도 전부. 보드를 손으로 그려 번호를 매기고, **지름길 진입/합류 지점**을 하나씩 검산한다.
- **★ 도착점 충돌 예외 누락.** `nextPos != DESTINATION` 조건이 없으면 정상 케이스를 실패로 판정한다.
- **★ `board[currentPos] = false` 순서.** 비우기 → 점유 순서.
- **★ 실패를 `return 0` 으로 하는 것의 전제.** 최댓값 문제라 안전하다. **최솟값 문제였다면 `INF` 여야 한다.**
- **`horsePos`, `board` 를 전역으로 두고 초기화 안 함.** 후보 100만 개가 전부 오염된다. **지역 배열 `{0}` 이 안전.**
- **말 번호 1~4 인덱싱.** `horsePos[5]` 로 잡고 0번은 비워둔다. 0-based로 섞으면 헷갈린다.
- **점수를 지나가는 칸까지 누적.** 도착 칸만 센다.
- **T-loop 마다 `maxAnswer` 초기화 누락.**

## 7. 백지 재현 체크리스트
- [ ] 보드를 **`next[위치][칸수]` 전이표**로 만들 수 있는가
- [ ] 지름길 진입점(`10`, `20`, `30`)과 합류점을 표에 정확히 반영했는가
- [ ] DFS가 **매 턴 말 1~4 중 하나** 고르는 중복순열인가 (`4^10`)
- [ ] 상태가 **`horsePos[]` + `board[]` 두 배열**뿐임을 아는가
- [ ] 충돌 검사에 **도착점 예외**를 넣었는가
- [ ] 비우기 → 점유 **순서**를 지켰는가
- [ ] 실패를 `return 0` 으로 처리해도 되는 이유(최댓값 문제)를 아는가
- [ ] 지역 배열 `{0}` 으로 후보마다 리셋되는가

## 8. 한 줄 요약
"보드를 **`next[위치][칸수]` 전이표로 펼치면** 지름길 분기가 사라진다. 시뮬은 **표 조회 + 충돌 검사** 10줄."
