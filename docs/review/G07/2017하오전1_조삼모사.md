## 1. 문제 요약
N명을 **두 팀으로 나누되, 각 팀의 인원은 정확히 N/2명**이어야 한다.

사람 `i`, `j` 가 같은 팀일 때의 시너지가 `MAP[i][j]` 로 주어진다.
한 팀의 능력치는 **같은 팀의 모든 두 사람 쌍 (i, j)** 에 대해 `MAP[i][j] + MAP[j][i]` 를 모두 더한 값.

**두 팀의 능력치 차이의 절댓값을 최소로** 만드는 분할을 구한다.

## 2. 필요한 이론
→ [G07 — 조합 (절반 분할)](../../theory/G07_완전탐색시뮬.md)

[G04 31번 조합](../G04/31_BOJ_15650_15655_15664_조합.md)을 그대로 쓴다. **후보 = N명 중 N/2명을 고르는 조합.**

```
N = 10 이면  C(10, 5) = 252 가지
N = 20 이면  C(20, 10) = 184,756 가지
```
각 후보마다 시너지 합을 계산하므로 `184756 × O(N²)` 정도 — 통과한다.

> **★ 이 문제의 포인트: "한 팀만 고르면 나머지는 자동으로 결정된다."**
> `num_of_cases` 에 담은 것이 morning 팀이고, **거기 없는 사람이 전부 dinner 팀**이다.
> 두 팀을 각각 고르려 들면 로직이 복잡해지고 중복도 폭증한다.

## 3. 코드 흐름
```
main()
 └ T-loop:
      input()                  N, MAP[N][N]
      halfN = N / 2
      minAnswer = INF
      DFS(0, 1)
      printf(minAnswer)

DFS(depth, start):
   if (depth == halfN):        ★ 절반만 고르면 완성
      tmp = calculate()
      minAnswer = min(minAnswer, tmp)
      return
   for i in start..N:
      num_of_cases[depth] = i
      DFS(depth + 1, i + 1)    ★ 조합 (i+1)
```

## 4. 핵심 코드

### ★ 절반 조합
```c
void DFS(int depth, int start)
{
    // halfN명을 모두 고르면 한 팀 완성
    if (depth == halfN)
    {
        int tmp = calculate();
        if (tmp < minAnswer) minAnswer = tmp;
        return;
    }

    // start부터 N까지 사람 번호 하나씩 선택
    for (int i = start; i <= N; i++)
    {
        num_of_cases[depth] = i;

        // 다음 사람은 현재보다 뒤에서만 고름
        DFS(depth + 1, i + 1);      // ★ i + 1 = 조합
    }
}
```

[G04 31번](../G04/31_BOJ_15650_15655_15664_조합.md)과 **완전히 같은 코드**다. `depth == M` 이 `depth == halfN` 으로 바뀐 것뿐.

> **`DFS(depth+1, i)` 로 쓰면 중복조합**이 되어 같은 사람을 두 번 고른다. `i + 1` 필수.

### 팀 나누기 — 고른 쪽을 표시하고 나머지는 자동
```c
int calculate()
{
    bool isMorning[MAX] = { 0 };
    int morning[MAX] = { 0 }, dinner[MAX] = { 0 };
    int mcnt, dcnt;

    // 현재 DFS에서 고른 사람들을 morning 팀으로 표시
    for (int i = 0; i < halfN; i++)
        isMorning[num_of_cases[i]] = true;

    // 전체 사람을 보며 morning / dinner로 나누기
    mcnt = dcnt = 0;
    for (int i = 1; i <= N; i++)
    {
        if (isMorning[i] == true) morning[mcnt++] = i;
        else                      dinner[dcnt++] = i;
    }
    ...
}
```

**`isMorning` 은 지역 배열이라 매 호출마다 `{0}` 으로 초기화**된다. 전역으로 빼면 명시적 초기화가 필요하다.

### 시너지 합 — 모든 쌍
```c
sum1 = sum2 = 0;

// 각 팀 내부의 모든 두 사람 쌍(i, k)에 대해 MAP[a][b] + MAP[b][a]
for (int i = 0; i < mcnt - 1; i++)
    for (int k = i + 1; k < mcnt; k++)
        sum1 += MAP[morning[i]][morning[k]] + MAP[morning[k]][morning[i]];

for (int i = 0; i < dcnt - 1; i++)
    for (int k = i + 1; k < dcnt; k++)
        sum2 += MAP[dinner[i]][dinner[k]] + MAP[dinner[k]][dinner[i]];

return abs(sum1 - sum2);
```

**`k = i + 1`** 로 **각 쌍을 정확히 한 번씩** 센다. `k = 0` 부터 돌면 `(a,b)` 와 `(b,a)` 를 두 번 세고, 자기 자신 `(a,a)` 도 포함된다.

그리고 쌍마다 **`MAP[a][b] + MAP[b][a]` 둘 다** 더한다 — 시너지가 비대칭이기 때문.

### 자체 `abs`
```c
int abs(int x)
{
    return (x > 0) ? x : -x;
}
```
`<stdlib.h>` 를 안 쓰므로 직접 구현. [G04 33번](../G04/33_BOJ_6603_10819_로또차이를최대로.md)과 같은 관용구.

## 5. 예제 손 추적 — `N = 4`

```
MAP =    0  1  2  3
         4  0  5  6
         7  1  0  2
         3  4  5  0
```
`halfN = 2`.

### 탐색되는 조합
```
DFS(0, 1):
  i=1 → DFS(1, 2): i=2 → {1,2}
                   i=3 → {1,3}
                   i=4 → {1,4}
  i=2 → DFS(1, 3): i=3 → {2,3}
                   i=4 → {2,4}
  i=3 → DFS(1, 4): i=4 → {3,4}
  i=4 → DFS(1, 5): 루프 안 돎
```
**6가지 = `C(4,2)`** ✓

### `{1, 2}` 를 morning 으로 고른 경우
```
morning = [1, 2],  dinner = [3, 4]        ← 나머지가 자동으로 dinner

sum1 = MAP[1][2] + MAP[2][1] = 1 + 4 = 5
sum2 = MAP[3][4] + MAP[4][3] = 2 + 5 = 7

차이 = |5 - 7| = 2
```

### `{3, 4}` 를 morning 으로 고른 경우
```
morning = [3, 4],  dinner = [1, 2]

sum1 = MAP[3][4] + MAP[4][3] = 7
sum2 = MAP[1][2] + MAP[2][1] = 5

차이 = |7 - 5| = 2      ← {1,2} 와 같은 분할!
```

> ⚠️ **`{1,2}` 와 `{3,4}` 는 같은 분할이다.** 어느 쪽을 morning 이라 부르든 차이는 같다.
> 즉 **각 분할이 정확히 두 번씩 탐색**된다. 답은 같으므로 정답에 영향은 없고, 시간만 2배 든다.
>
> **줄이려면**: 1번 사람을 항상 morning 에 고정하고 나머지 `N-1` 명 중 `halfN-1` 명을 고르면 `C(N-1, halfN-1)` 로 절반이 된다.
> ```c
> num_of_cases[0] = 1;
> DFS(1, 2);          // 1번은 이미 고정
> ```
> A형 범위에서는 안 해도 통과한다.

### `mcnt - 1` 루프 경계
`mcnt = 2` 면 `for (i = 0; i < 1; i++)` → `i = 0` 만, 그 안에서 `k = 1`.
**쌍 하나** ✓ (`C(2,2) = 1`)

`mcnt = 3` 이면 쌍이 3개: `(0,1) (0,2) (1,2)` ✓

## 6. 함정 / 예상 함정
- **★★ `DFS(depth+1, i)` 로 씀** → 중복조합이 되어 같은 사람을 두 번 고른다. **`i + 1`**.
- **★★ 두 팀을 각각 고르려 함.** 한 팀만 고르면 나머지는 자동.
- **★ 쌍 루프를 `k = 0` 부터.** 같은 쌍을 두 번 세고 `(a,a)` 도 포함된다. **`k = i + 1`**.
- **★ `MAP[a][b]` 만 더함.** 시너지가 비대칭이라 **`MAP[a][b] + MAP[b][a]` 둘 다** 필요하다.
- **★ 최솟값인데 `minAnswer` 를 0으로 초기화.** `INF` 로.
- **`isMorning` 을 전역으로 두고 초기화 안 함.** 앞 후보의 표시가 남는다. **지역 배열 `{0}` 이 안전.**
- **`halfN = N / 2`** 를 입력 직후 한 번 계산. N은 항상 짝수라고 문제가 보장한다.
- **T-loop 초기화** — `minAnswer`.

## 7. 백지 재현 체크리스트
- [ ] **한 팀만 고르면 나머지가 자동 결정**됨을 아는가
- [ ] 조합 재귀 `DFS(depth+1, i+1)` 를 쓰는가
- [ ] 종료 조건이 `depth == halfN` 인가
- [ ] 쌍 루프가 `k = i + 1` 인가 (각 쌍 정확히 한 번)
- [ ] `MAP[a][b] + MAP[b][a]` **둘 다** 더하는가
- [ ] `minAnswer = INF` 로 초기화했는가
- [ ] 각 분할이 **두 번씩** 탐색된다는 것과, 1번 고정으로 반으로 줄이는 법을 아는가

## 8. 한 줄 요약
"**한 팀만 조합으로 고르면** 나머지는 자동. 쌍은 `k = i+1` 로 한 번씩, 시너지는 **양방향 둘 다.**"
