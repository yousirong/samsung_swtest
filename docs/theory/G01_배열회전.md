# G01. 배열 회전·변환

> 상태: ✅ 작성 완료

## 언제 이 유형인가
- "시계 / 반시계 방향으로 90도(또는 45도) 회전"
- "테두리를 따라 R칸 민다"
- "상하 반전 / 좌우 반전"
- "달팽이 모양으로 채운다"
- "2^L 크기 블록 단위로"

전부 **좌표를 옮기는 문제**다. 값을 계산하는 게 아니라 `dst[?][?] = src[?][?]` 의 인덱스 공식을 세우는 게 전부다.

---

## ★ 이 그룹의 단 하나의 원칙

> **읽는 배열과 쓰는 배열을 분리한다.**

```c
void copyMap(int copy[MAX][MAX], int original[MAX][MAX])
{
    for (int r = 1; r <= N; r++)
        for (int c = 1; c <= M; c++)
            copy[r][c] = original[r][c];
}

// 모든 변환의 시작은 항상 이 한 줄
copyMap(temp, MAP);
// 이후 temp 에서 읽고 MAP 에 쓴다
```

in-place 로 돌리려는 순간 이미 옮긴 값을 다시 읽게 된다. 12·13·14·15 네 파일이 **전부** 이 패턴으로 시작한다. 예외 없다.

---

## 핵심 인덱스 공식 (1-indexed, N행 M열)

```c
// 상하 반전
MAP[r][c] = temp[N + 1 - r][c];

// 좌우 반전
MAP[r][c] = temp[r][M + 1 - c];

// 시계 90도  — 먼저 N ↔ M 을 swap 한 뒤 아래 공식
MAP[r][c] = temp[M + 1 - c][r];

// 반시계 90도 — 역시 N ↔ M swap 이후
MAP[r][c] = temp[c][N + 1 - r];
```

> **시계/반시계 90도는 배열 크기가 바뀐다.** N×M → M×N.
> 공식을 쓰기 **전에** `N` 과 `M` 을 먼저 교환하고, 교환된 값 기준으로 루프를 돈다. ([14번](../review/G01/14_BOJ_16935_배열돌리기3.md) 참고)

### 0-indexed 로 쓸 때
`N + 1 - r` → `N - 1 - r`. 이 레포는 전부 1-indexed 이므로 `+1` 형태로 외운다.

## 세 가지 회전 단위

### 1) 전체 배열 회전 — 위 공식 그대로

### 2) 테두리(층) 단위 회전 — [13번](../review/G01/13_BOJ_16926_16927_배열돌리기1_2.md)
층을 하나씩 잡고, **테두리 좌표를 순서대로 배열에 담아 1차원 회전 문제로 바꾼다.**

```c
// 층 순회: 층 개수 = min(N, M) / 2
for (int s = 0; s < step; s++) {
    rotatestep(sr, sc, n, m, R);
    sr++; sc++; n -= 2; m -= 2;   // 한 겹 안쪽으로
}
```

테두리를 담을 땐 **모서리 중복에 주의**해서 네 변을 이어 붙인다.
```c
for (c = sc;     c <= ec; c++) arr[index++] = {sr, c};  // 윗변 (전부)
for (r = sr + 1; r <= er; r++) arr[index++] = {r, ec};  // 우변 (모서리 제외)
for (c = ec - 1; c >= sc; c--) arr[index++] = {er, c};  // 아랫변
for (r = er - 1; r >= sr+1; r--) arr[index++] = {r, sc}; // 좌변
```

이제 회전은 인덱스 시프트다.
```c
int newIndex = (i - rotateCount) % index;
newIndex = newIndex < 0 ? newIndex + index : newIndex;   // ★ 음수 보정
MAP[arr[newIndex].r][arr[newIndex].c] = temp[arr[i].r][arr[i].c];
```

### 3) 블록(2^L) 단위 회전 — [15번](../review/G01/15_BOJ_20327_배열돌리기6.md)
블록의 **좌상단 좌표를 `divide` 간격으로 순회**하고, 블록 내부만 변환한다.

```c
int divide = (1 << level);
for (int r = 1; r <= S; r += divide)
    for (int c = 1; c <= S; c += divide)
        flipUpDownDivide(r, c, divide);   // 이 블록 하나만 처리
```

> **"블록 위치만 바꾸기" 트릭** — 15번의 5~8번 연산.
> `전체 배열을 변환` + `각 블록을 역변환` = 블록 내부는 원상복구되고 위치만 바뀐다.
> ```c
> void splitUpDown(int level) {
>     flipUpDown(N);       // 전체를 상하 반전
>     flipUpDown(level);   // 각 블록도 상하 반전 → 내부만 복구
> }
> ```
> 시계 회전의 역변환은 반시계 회전이다: `splitClockwise = clockwise(N) + counterClockwise(level)`

## 회전 횟수 줄이기
```c
count = D / 45;                       // 45도 단위 회전 횟수 (12번)
count = count > 0 ? count : -count;   // 음수는 방향으로만 쓰고 횟수는 절댓값
```
90도 회전이면 `R % 4`, 테두리 회전이면 `R % (테두리 길이)`. **안 줄이면 시간 초과**가 난다.

---

## 함정 체크리스트
- [ ] in-place 로 돌리다 덮어쓰기 사고 → `copyMap(temp, MAP)` 을 먼저
- [ ] 90도 회전에서 `N`, `M` swap 을 안 하거나, swap 전 값으로 루프를 돔
- [ ] 테두리 좌표 수집 시 네 모서리를 중복으로 넣음
- [ ] 음수 나머지 보정(`+ index`) 누락 → 인덱스 음수
- [ ] 회전 횟수를 `% 주기` 로 안 줄여 시간 초과
- [ ] 테스트케이스마다 배열 초기화 누락 (12번은 T-loop 구조)
- [ ] 정사각형 가정으로 짜서 N×M 에서 깨짐
