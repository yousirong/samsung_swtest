# G12. 미완성 — 복습 후 완성

> 상태: ✅ 설계 문서 작성 완료 — **구현만 남았다.**

이 그룹에는 **이론이 없다.** 앞에서 정리한 모든 카드를 실제로 써먹는 자리다.

## 대상

### 2021 상반기 오후 1번 — 나무 타이쿤
- 소스: [`swtest/코드트리_2021_상반기오후1번_나무타이쿤.cpp`](../../swtest/코드트리_2021_상반기오후1번_나무타이쿤.cpp)
- 현재 상태: **9줄 스텁.** `#include`, `MAX_N/MAX_M` 정의, `int T; int N, M;` 뿐. `main()` 없음
- 유일한 미해결 문제다

## 진행 방식

다른 그룹과 순서가 반대다. **노트를 먼저 쓰고 코드를 나중에 쓴다.**

1. 문제 지문을 읽고 노트 §1(문제 요약)·§2(필요한 이론)를 채운다
2. §3(코드 흐름)을 **설계 문서로** 작성한다 — 아직 코드는 한 줄도 없다
3. 어떤 이론 카드가 걸리는지 링크한다 (회전? 시뮬? BFS?)
4. 그 설계대로 구현한다
5. 구현하며 부딪힌 것을 §4(함정)에 기록한다
6. §5(백지 재현 체크리스트)로 닫는다

이 순서가 곧 **실전 A형의 순서**다. G12 는 그 리허설이다.
