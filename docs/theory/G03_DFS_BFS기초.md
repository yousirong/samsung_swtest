# G03. DFS / BFS 기초

> 상태: ✅ 작성 완료

## 언제 이 유형인가
- "연결되어 있는", "퍼져나가는", "몇 개의 덩어리"
- 인접 관계로 주어진 그래프 순회
- **최단 거리를 물으면 BFS**, 단순 도달 여부/개수면 둘 다 가능

이 그룹은 **정점 번호로 주어진 그래프**를 다룬다. 같은 탐색을 격자 위에서 하는 것이 [G05](G05_그리드탐색심화.md)다.

---

## 두 탐색의 차이는 "다음에 뭘 볼지"뿐

| | DFS | BFS |
|---|---|---|
| 자료구조 | **재귀 호출 스택** | **큐** |
| 진행 | 한 방향으로 끝까지 | 가까운 것부터 층층이 |
| 방문 표시 시점 | 함수 진입 직후 | **큐에 넣는 순간** ★ |
| 최단 거리 | ✗ | ✓ |
| 코드 길이 | 짧다 | 조금 길다 |

---

## 인접 행렬 — A형의 기본 선택
```c
int MAP[MAX][MAX];    // MAP[a][b] == 1 이면 a-b 연결

// 무방향 그래프이므로 양쪽 모두 연결
MAP[n1][n2] = 1;
MAP[n2][n1] = 1;
```

인접 리스트보다 느리지만 **"번호가 작은 정점부터"** 조건을 공짜로 만족한다.
`for (c = 1; c <= N; c++)` 로 돌면 그게 곧 오름차순이다. A형은 N이 작아 행렬이 유리하다.

---

## DFS — 재귀 세 줄
```c
void DFS(int node)
{
    visit[node] = true;          // ★ 함수 진입 직후 방문 처리
    printf("%d ", node);         // (방문 순서를 물으면)

    for (int c = 1; c <= N; c++)
    {
        if (MAP[node][c] == 0 || visit[c] == true) continue;
        DFS(c);                  // 깊이 우선
    }
}
```
`연결 안 됨 || 이미 방문` 을 `continue` 로 거르는 게 관용구다.

## BFS — 큐 한 개
```c
void BFS(int node)
{
    int rp, wp;
    rp = wp = 0;

    queue[wp++] = node;
    visit[node] = true;          // ★ 시작 노드도 반드시 방문 처리

    while (rp < wp)              // 큐가 빌 때까지
    {
        int out = queue[rp++];
        printf("%d ", out);

        for (int c = 1; c <= N; c++)
        {
            if (MAP[out][c] == 0 || visit[c] == true) continue;

            queue[wp++] = c;
            visit[c] = true;     // ★★ 넣는 순간 찍는다
        }
    }
}
```

큐는 [G02 19번](../review/G02/19_BOJ_10845_18258_큐_큐2.md)에서 만든 그 큐다. `while (rp < wp)` 가 "큐가 비지 않았다"는 뜻.

---

## ★★ BFS 에서 visit 을 찍는 시점

이 그룹 전체에서 가장 중요한 한 줄이다.

```c
queue[wp++] = c;
visit[c] = true;     // ← 여기 (넣을 때)
```

**꺼낼 때 찍으면 안 된다.**
```c
int out = queue[rp++];
visit[out] = true;   // ✗ 틀림
```

이유: 정점 A와 B가 둘 다 C에 연결되어 있고 A, B가 큐에 먼저 들어갔다고 하자.
꺼낼 때 찍는 방식이면 A를 처리할 때 C가 큐에 들어가고, B를 처리할 때 **C가 아직 방문 표시가 없어 또 들어간다.**
같은 정점이 큐에 여러 번 쌓이고, 최악의 경우 큐가 폭발하거나 거리 계산이 틀린다.

> 이 규칙은 격자 BFS([G05](G05_그리드탐색심화.md))와 기출 전체에서 그대로 적용된다.

---

## visit 초기화
한 프로그램에서 DFS와 BFS를 둘 다 돌리면 사이에 초기화가 필요하다.
```c
DFS(V);
for (int i = 1; i <= N; i++) visit[i] = false;   // ★
BFS(V);
```
기출에서는 이게 **테스트케이스마다 / 완전탐색 후보마다** 초기화하는 습관으로 이어진다.

---

## 함정 체크리스트
- [ ] **BFS에서 visit 을 dequeue 시점에 찍음** → 같은 노드가 큐에 중복 삽입 ★★
- [ ] **시작 노드를 방문 처리하지 않음** → 자기 자신으로 되돌아옴
- [ ] 무방향 그래프인데 간선을 한 방향만 등록 (`MAP[n1][n2]` 만)
- [ ] DFS/BFS 를 연달아 쓸 때 `visit` 초기화 누락
- [ ] 정점 번호가 1-indexed 인지 0-indexed 인지 혼동
- [ ] "번호가 작은 것부터" 조건이 있는데 인접 리스트를 정렬 없이 사용
- [ ] 큐 배열 크기 부족 — `rp/wp` 는 전진만 한다 ([G02](G02_스택큐덱.md))
- [ ] DFS 재귀 깊이가 깊어 스택 오버플로 (A형 범위에선 드물다)
