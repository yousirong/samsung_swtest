# G06. 격자·상태 회전

> 상태: 🔲 미작성 — G06 그룹 복습 시작할 때 채운다.
> [G01 배열 회전](G01_배열회전.md) 의 실전판. 회전이 **단독으로 끝나지 않고** 시뮬레이션·탐색과 붙는다.

## 언제 이 유형인가
- "부분 격자를 회전시킨다", "원판을 K칸 돌린다"
- "주사위를 굴린다" — 좌표가 아니라 **면(state)** 이 회전한다
- "이전 세대를 뒤에서부터 보면서 90도 꺾는다" (드래곤 커브)
- 회전 후 **후처리**(인접 같은 수 제거, 얼음 녹기)가 따라붙는다

## 회전의 세 가지 층위
1. **좌표 회전** — 격자 값이 자리를 옮긴다 (회전하는 빙하)
2. **상태 회전** — 좌표는 그대로, 객체의 내부 상태가 바뀐다 (정육면체 굴리기, 팔각의자)
3. **방향열 회전** — 진행 방향의 수열을 회전시켜 다음 세대를 만든다 (드래곤 커브)

## 핵심 패턴

### ① 좌표 회전 — 블록 단위
```c
// 2^level 블록의 좌상단만 순회
int divide = (1 << level);
for (int r = 1; r <= S; r += divide)
    for (int c = 1; c <= S; c += divide)
        rotate(r, c, divide);

// 시계 90도 (블록 로컬, 0-based)
for (int r = 0; r < size; r++)
    for (int c = 0; c < size; c++)
        MAP[sr + r][sc + c] = tmpMAP[size - 1 - c][r];
```

### ② 상태 회전 — 주사위 6면
```c
// tmp 에 통째로 담고 나서 덮어쓴다 (순차 대입 금지)
int tmp[6] = { cube.up, cube.left, cube.top, cube.right, cube.down, cube.bottom };

cube.top    = tmp[1];   // left   -> top
cube.right  = tmp[2];   // top    -> right
cube.bottom = tmp[3];   // right  -> bottom
cube.left   = tmp[5];   // bottom -> left
// 굴리는 축에 수직인 두 면은 고정
```

### ③ 방향열 회전 — 세대 확장
```c
// 뒤에서부터 읽어 +1(mod 4) 해서 뒤에 붙인다 (0-based가 명확)
for (int i = 0; i < length; i++)
    dir[length + i] = (dir[length - 1 - i] + 1) % 4;
length *= 2;
```

### ④ 원형 배열 회전 — 인덱스 시프트
```c
if (d == COUNTER_CLOCKWISE) k = -k;    // 방향을 부호로 흡수

int newIndex = (i - k) % index;
newIndex = (newIndex < 0) ? newIndex + index : newIndex;   // ★ 음수 보정
circle[r][newIndex] = arr[i];
```

### ★ 회전 뒤에는 반드시 후처리가 붙는다
```c
// 판정과 반영을 분리한다 (동시성)
int MARK[MAX][MAX] = { 0 };
for (r, c) if (조건) MARK[r][c] = 1;      // 판정만
for (r, c) MAP[r][c] -= MARK[r][c];       // 한 번에 반영
```

## 자주 쓰는 관용구
- [ ] 부분 격자 회전: 좌상단 `(sr, sc)` 를 `2^L` 간격으로 순회 → 블록 내부만 회전
- [ ] 원형 배열 회전: 실제로 옮기지 말고 **offset 인덱스**만 이동 (`(i + K) % M`)
- [ ] 주사위: `up/down/north/south/east/west` 6변수 swap 을 방향별로 4가지 준비
- [ ] 전파형 회전(팔각의자): 좌우로 재귀/반복 전파, 방향은 매번 반전
- [ ] 회전 결과는 항상 temp 에 → 전부 끝난 뒤 반영 (동시성)

## 함정 체크리스트
- [ ] 회전 후처리를 **회전 도중**에 적용해 연쇄 반응이 일어남
- [ ] 원판/원형 배열에서 1번과 M번이 인접임을 놓침
- [ ] 회전 방향(시계/반시계)과 인덱스 공식 불일치
- [ ] 주사위 면 번호와 방향 배열의 대응이 어긋남
- [ ] "동시에 사라진다" 를 순차 처리
