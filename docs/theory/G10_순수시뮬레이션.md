# G10. 순수 시뮬레이션 (규칙 충실 구현)

> 상태: ✅ 작성 완료
> **새로운 이론이 없다.** 지문의 규칙을 그대로 코드로 옮기는 것이 전부다. 그래서 오히려 A형에서 가장 많이 나오고, 가장 많이 틀린다. 이 그룹의 목적은 이론 습득이 아니라 **구현 체력과 지문 독해 정확도**다.

## 언제 이 유형인가
- 규칙이 번호 매겨 나열되어 있다 ("1. 먼저 ~한다 2. 그 다음 ~한다")
- 완전탐색도 없고 최단거리도 없다. 그냥 시키는 대로 하면 된다
- 대신 규칙이 5~10개고, 예외 조건이 촘촘하다

## 이 유형에서 이기는 법
1. **지문의 규칙에 번호를 매기고, 함수 하나에 규칙 하나를 대응**시킨다
   → `moveAll()`, `mergeAtoms()`, `cleanDust()` 처럼
2. **`printMap()` 을 먼저 만든다.** 디버깅 시간의 대부분을 여기서 회수한다
3. 예제 입력을 **한 턴씩** 손으로 따라가며 출력과 대조한다
4. 규칙의 **순서**를 지문에서 그대로 옮긴다. 임의로 합치지 않는다

## 반복 등장하는 하위 패턴
- [ ] **동시 이동**: 모두가 동시에 움직인다 → `tmpMAP` 에 쌓고 한 번에 반영
- [ ] **한 칸에 여러 개**: 격자에 값 하나만 두지 말고 리스트/카운트로 관리 (원자 충돌, 이상한 윷놀이)
- [ ] **원형 격자**: `(r + dr + N) % N` — `+ N` 누락 주의 (원자 충돌, 무빙워크)
- [ ] **방향 회전 탐색**: 갈 곳이 없으면 45도/90도씩 돌려가며 재시도 (자율주행, 술래잡기 체스)
- [ ] **우선순위 이동**: 방향 우선순위 배열이 주어진다 (모노폴리)
- [ ] **정렬 + 카운팅**: 행/열마다 (수, 등장횟수) 정렬 (격자 숫자 놀이)
- [ ] **쌓임(스택) 관리**: 말 위에 말이 쌓인다 (이상한 윷놀이)
- [ ] **계절 루프**: 봄·여름·가을·겨울 4단계 반복 (바이러스 실험)

## 함정 체크리스트
- [ ] "동시에" 를 순차 처리 ★ 이 그룹 최빈 실수
- [ ] 규칙 순서를 바꿔 구현 (지문 2번을 3번보다 뒤에)
- [ ] 원형 인덱스에서 `+ N` 누락 → 음수 인덱스
- [ ] 종료 조건을 잘못 잡아 무한 루프 / 조기 종료
- [ ] 턴 카운트를 1부터 세는지 0부터 세는지
- [ ] 테스트케이스마다 전역 상태 초기화 누락 (T-loop)
- [ ] 지문에 있는 예외 한 줄을 통째로 놓침 → **규칙 번호 대조로 방지**
