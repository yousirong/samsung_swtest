# 삼성 SW 역량테스트 A형 — 복습 진도

전체 **68개 소스** (BOJ 기초 30 + 코드트리 기출 38) 를 유형별로 재정렬한 복습 노트 인덱스.
> ⚠️ 이 중 **`격자 숫자 놀이` 소스는 `바이러스 백신` 의 복제본**이라 실제 문제 수는 **67개**다 ([상세](review/G10/2019상오후1_격자숫자놀이.md)).
`←` 마커가 지금 할 차례다. 한 번에 하나만 유지한다.

**진행 방식** — 소스를 먼저 열지 않는다.
`①문제 요약 → ②접근법을 말로 → ③소스 열어 대조 → ④함정 기록 → ⑤백지 재현 체크리스트 → ⑥한 줄 요약`

**노트 구성** (8절)
`1 문제 요약 · 2 필요한 이론 · 3 코드 흐름 · 4 핵심 코드 · 5 예제 손 추적 · 6 함정 · 7 백지 재현 체크리스트 · 8 한 줄 요약`
§5 손 추적의 값은 전부 **실제 컴파일·실행으로 검증**한 것이다.

**검증** — 그룹을 마칠 때마다 `python3 docs/check.py` (깨진 링크 + 진도 카운트)

## 참고

- **원본 vs 리뷰본**: 날짜 폴더(`260502/`, `260503/`, `260508/`, `260511/`, `260619/`)의 6개 파일은 대회 당일 원본이다. 별도 노트를 만들지 않고, 해당 문제 노트의 "원본 vs 리뷰본" 절에서 비교 재료로만 쓴다.
- **단일 파일 실행**: VS 프로젝트는 `main()` 이 여러 개라 통짜 빌드가 안 된다. 코드를 돌려볼 땐 파일 하나씩 컴파일한다.
  ```bash
  cd swtest && g++ -O2 -o /tmp/a.out "파일명.cpp" && /tmp/a.out < input.txt
  ```
- **⚠️ 한 파일에 프로그램이 여러 개인 소스 7종** — 전역 중복 정의로 위 방법이 안 통한다.
  `28`, `29`, `30`, `31`, `32`, `33`, `37`. 블록을 뽑아 실행한다.
  ```bash
  python3 docs/split.py 30_BOJ_15649_15654_15663_순열.cpp           # 블록 목록
  printf '4 2\n' | python3 docs/split.py 30_...순열.cpp 15649        # 특정 블록 실행
  ```
